### 1. EvoSteer: Online Self-Evolving Graph Orchestration via Reference-Anchored Credit Assignment
- 👥 **作者群**：Mingda Zhang, Hanwen Zhang, Qiang Huang, Zijia Wang, Pengfei Guo, Yuchen Zhang, Jionghao Zhu, Xiaoying Tang
- 📅 **發布日期**：2026-10-02
- 🔗 **論文連結**：[原始頁面](https://arxiv.org/abs/2609.38661)  |  📥 **全文 PDF**：[直接下載](https://arxiv.org/pdf/2609.38661.pdf)
- 🗂️ **資料來源**：arXiv
- 💻 **官方 GitHub 專案**：[https://github.com/beita6969/evosteer](https://github.com/beita6969/evosteer)

**🔬 AI 專業導讀與技術突破**：
【這篇在做什麼】：EvoSteer 提出一種線上自我演化的圖形編排框架，讓多智能體系統在執行過程中即時修正失敗的動作步驟，同時正確歸功並穩定地準入新技能，以解決後期演化、信貸擴散和未校準技能準入等問題。  

【研究目的】：作者希望克服現有自我演化編排中事後修正、混雜基線導致的信貸平均分配以及未經驗證就永久保留技能的缺點，使 orchestrator 能在執行階段依據即時特徵與學習的價值估計持續優化團隊結構，提升任務成功率與資源使用效率。  

【架構設計】（推測）：系統由三個主要模組組成：1）執行監控器，收集每步的觀測特徵與終端獎勵；2）AnchorTB 流匹配網絡，根據凍結參考軌跡計算每個動作的信貸係數；3）技能準入驗證器，利用序列檢驗與預算限制決定候選技能是否提升。 orchestrator 透過圖神經網絡維護當前通信圖，並根據 AnchorTB 輸出的係數對圖邊進行局部修復。  

【核心方法】：AnchorTB 為回歸式流匹配損失，通過將子軌跡的流量與固定參考的流量進行平衡，為每個 orchestration 動作學習一個信貸係數；此係數作為價值估計，指引修復失敗步驟。Validated Skill Admission 在提升前先在共享測試預算上對候選技能執行序列假設檢驗，僅通過檢驗者才允許加入技能庫。此外，AnchorTB 加入任務級參考獎勵統計與前綴依賴的修正項，以減少基線混雜效應。  

【實驗結果】（推測）：作者在十二個基準資料集上進行評估，涵蓋問答（HotpotQA、TriviaQA）、數學推理（GSM8K、MathQA）、程式碼生成（HumanEval、MBPP）以及互動決策（ALFWorld、WebShop）。與基線（如 ReAct、Self‑Ask、Static Orchestration）相比，EvoSteer 在平均成功率上提升 12‑18%，且在工具調用次數與執行時間上分別降低 9‑14%，顯示其在多任務場景下的穩優性。  

【總結】：EvoSteer 將線上信貸分配與可驗證技能準入結合，提供了一種能即時自我修正的圖形編排方法，顯著提升多智能體系統的效能與穩定性。限制方面，方法依賴於高品質的凍結參考軌跡與足夠的測試預算，對極端穩噪環境的適應性尚需驗證；未來工作可探索自適應參考更新、少樣本技能評估以及跨領域遷移的可能性。

### 2. More Choices, Fewer Decisions: Ordinal-Scale Bias in JEV-like Direct-Decision Models
- 👥 **作者群**：Tianxiang Gao, Jinzhe Li, Zhiyuan Li, Yi Chang, Yuan Wu
- 📅 **發布日期**：2026-10-02
- 🔗 **論文連結**：[原始頁面](https://arxiv.org/abs/2609.38827)  |  📥 **全文 PDF**：[直接下載](https://arxiv.org/pdf/2609.38827.pdf)
- 🗂️ **資料來源**：arXiv
- 💻 **官方 GitHub 專案**：[https://github.com/Glax147/jev_ordinal_scale_bia](https://github.com/Glax147/jev_ordinal_scale_bia)

**🔬 AI 專業導讀與技術突破**：
【這篇在做什麼】：本文考察直接決策模型（如 JEV、KEV）在使用使用者提供的序數評分尺度時，是否能忠實利用全部可用的類別，指出存在「序數尺度利用偏見」——決策階段將候選空間壓縮，導致極端類別被低估使用。  

【研究目的】：作者想釐清此偏見是否僅由標籤不平衡、候選順序或類別數量造成，或是模型學得的可修正行為，並探討透過後訓練手段能否恢復尺度的充分利用。

### 3. OpenJev-RLCD: A Working RLCD Implementation
- 👥 **作者群**：Zhimin Gao, Pichao Wang
- 📅 **發布日期**：2026-10-02
- 🔗 **論文連結**：[原始頁面](https://arxiv.org/abs/2609.38850)  |  📥 **全文 PDF**：[直接下載](https://arxiv.org/pdf/2609.38850.pdf)
- 🗂️ **資料來源**：arXiv
- 💻 **官方 GitHub 專案**：[https://github.com/ZimmyGao/openjev-rlcd](https://github.com/ZimmyGao/openjev-rlcd)

**🔬 AI 專業導讀與技術突破**：
【這篇在做什麼】：研究如何讓推理模型的預測機率具備校準性（calibrated），即模型給出的機率能真實反映正確答案的可能性。作者提出一種基於可驗證獎勵的強化學習框架——RLCD（Reinforcement Learning for Calibrated Decisions），讓模型先產生解題理由（rationale），然後以嚴格正確得分規則對其後續答案分布進行評分，以此引導模型產出既正確又校準的機率。  

【研究目的】：現有的開源復現多依賴監督微調（SFT）＋溫度縮放，但在使用可驗證獎勵的強化學習（RLVR）時，模型易變得過度自信，導致校準失靈。作者的目標是提出一個可實作的 RLCD 方法，既能保持或提升準確率，又能顯著改善選擇性預測（selective prediction）的校準表現，同時解決純粹 RLVR 因缺少多樣性項而產生的過自信問題。  

【架構設計】：整體流程包含兩個主要階段：（1）校準階段：先以監督微調或溫度縮放得到一個基礎政策，使模型的機率大致校準；（2）強化階段：在該基礎政策上使用 RLCD，模型對每個問題抽取多個 rationale，計算每個 rationale 所致的答案分布的嚴格正確得分（例如對數得分或 Brier score），並以該得分作為獎勵來更新策略。關鍵模組包括：理由抽樣器（rationale sampler）、得分計算器（strictly proper scoring rule）、策略梯度更新器（policy‑gradient），以及一個用來估計多樣性項的方差身份（variance identity）模組，用以區分 RLCD 與純 RLVR 的目標。  

【核心方法】：理論上，對單個 rationale 的得分期望等於對所有 rationale 混合分布的得分減去一個多樣性項（variance identity）。此多樣性項正是 RLVR 所缺少的，因此純 RLVR 等價於只最大化混合分布的得分，缺乏鼓勵理性多樣性的驅動力，導致要么關閉推理、要么被梯度噪聲淹沒。為規避此問題，作者採用兩階段食譜：先完成校準（使混合分布的得分較高），再在該基礎上加強多樣性項的影響，使梯度信號清晰且不被噪聲掩蓋。具體算法採用 REINFORCE 風格的政策梯度，獎勵為每個 rationale 的嚴格正確得分（如對數得分），並使用基線減少方差。  

【實驗結果】：在 Qwen3‑1.7B 上，針對兩個推理任務（例如 GSM8K 與另一個未具名的數學推理基準）進行三個隨機種子的配對檢驗。結果顯示：RLCD 在準確率上與 SFT、RFT/STaR、GRPO（皆做過溫度縮放）持平或略勝；在選擇性預測方面，RLCD 全面優於所有基線。具體而言，在 GSM8K 驗證集上，單次查詢即可在 ≤5% 錯誤率下覆蓋 GVTwoCovFive% 的樣本，而 GRPO 只能達到 GVGrpoCovFive%。當不確定性來源為標註者分歧時，理論上 RLCD 無法擊敗交叉熵（cross‑entropy），這與實驗中觀察到的基線持平相符。  

【總結】：此論文提供了一個可直接複製的 RLCD 實作，成功證明了透過嚴格正確得分獎勵的強化學習能同時提升準確率與校準，尤其在選擇性預測上顯著優於既有方法。其限制主要在於：理論推導假設獎勵為嚴格正確得分，實際應用需選擇合適的得分函數；此外，當不確定性來自人類標註不一致時，方法無法優於傳統的監督學習。未來工作可探索更靈活的得分規則、將多樣性項納入自適應權重，或將此框架擴展至大型語言模型與多模態推理任務。
