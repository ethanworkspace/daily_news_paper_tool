### 1. In-Context Robot Learning with VLM Agents
- 👥 **作者群**：Dongzhou Cheng, Taoran Yi, Ye Fang, Xingwu Zhang, Fan Feng et al.
- 📅 **發布日期**：2026-09-16
- 🔗 **論文連結**：[原始頁面](http://arxiv.org/abs/2609.19138v1)  |  📥 **全文 PDF**：[直接下載](https://arxiv.org/pdf/2609.19138v1)
- 🗂️ **資料來源**：arXiv
- 💻 **官方 GitHub 專案**：[https://github.com/cheng-haha/GPT-Policy](https://github.com/cheng-haha/GPT-Policy)

**🔬 AI 專業導讀與技術突破**：
**【這篇在做什麼】**  
本文研究如何讓機器人在未見過的環境中，僅憑少量示範或互動回饋（例如人類示範影片、文字說明）即時學習並產出可執行的動作，而不需要重新訓練或修改任務特定參數——即「In‑Context Learning (ICL)」在具體機器人政策上的實現。

**【研究目的】**  
作者希望證明商用視覺語言模型（VLM，如 GPT‑6 Astra）是否具備從示範中抽取任務相關資訊、並將其轉換為可驗證、可執行的機器人工具‑動作序列的能力；進而建構一個通用代理框架（GPT‑Policy），作為機器人透過上下文學習適應新情境的實證基礎。

**【架構設計】（推測）**  
GPT‑Policy 包含三個主要模組：  
1. **Context Compiler**：負責從輸入的影片或圖像序列中提取與任務相關的視覺過渡，保留關鍵狀態變化；  
2. **VLM Agent**（如 GPT‑6 Astra）：根據編譯後的上下文產出機器人‑工具動作建議（例如關節角度或末端執行器姿態）；  
3. **Constrained Controller**：對 VLM 輸出的動作進行安全約束、可執驗證（碰撞檢測、達達容忍度），執行後回報實際結果，形成閉環回饋。  

**【核心方法】（推測）**  
- 使用人類示範影片作為上下文輸入，不提供動作標籤；

### 2. ElastiQP: An Always-Feasible QP Solver for Constrained Robot Control
- 👥 **作者群**：Daniel Morton, Jon Arrizabalaga, Zachary Manchester, Marco Pavone
- 📅 **發布日期**：2026-09-16
- 🔗 **論文連結**：[原始頁面](http://arxiv.org/abs/2609.19080v1)  |  📥 **全文 PDF**：[直接下載](https://arxiv.org/pdf/2609.19080v1)
- 🗂️ **資料來源**：arXiv
- 💻 **官方 GitHub 專案**：[https://github.com/StanfordASL/elastiqp](https://github.com/StanfordASL/elastiqp)

**🔬 AI 專業導讀與技術突破**：
【這篇在做什麼】：研究如何在機器人控制中使用二次規劃（QP）求解器時，即使加入越來越多的不等式約束（如避障、力矩限制）也能保證求解器永遠返回可行解，避免因約束衝突導致「infeasible」而無法產出控制指令。

【研究目的】：作者希望設計一種既能保持原始動態等式約束硬性滿足，又能在不等式約束衝突時自動釋放衝突部分的求解器，以提升控制器的可用性與安全性，同時不犧牲求解速度。

【架構設計】：ElastiQP 是一種修改後的雙活動集（dual active‑set）QP 求解器。其核心思想是對每個不等式約束引入一個精確的 L1 懲罰項（即松弛變數），而把所有松弛變數在求解過程中「解析摺疊」進去，使得壓縮線性系統的維度保持不變（僅含原始決策變數與 Lagrange 乘子），等式約束仍作為硬約束保留。

【核心方法】：在求解器內部，將每個不等式約束 \(a_i^\top x \le b_i\) 改寫為 \(a_i^\top x + s_i = b_i,\; s_i \ge 0\) 並加入懲罰項 \(\lambda \|s_i\|_1\) 到目標函數；透過 KKT 條件推導，發現松弛變數 \(s_i\) 可被消去，僅留下一個與原始 QP 大小相同的線性系統。求解過程保持活動集更新的雙重迭代，但每次迭代只需解一個固定大小的線性方程組。實作上採用 C++ header‑only 庫，並提供 Python/JAX 包裝。

【實驗結果】：作者在多個機器人控制基準（包括姿態控制、足端力控制與軌跡追蹤）上進行測試。在所有可行約束情況下，ElastiQP 的平均求解時間達到微秒級別，與目前領先的 OSQP、qpOASES 等求解器相當或略優。當約束集變得不可行時，ElastiQP 能在毫秒級內返回一個僅違反衝突不等式項的近似解，速度比最佳替代求解器快 up to 40×，且違反量被嚴格限制在對應的松弛變數上。

【總結】：ElastiQP 提供了一種「永遠可行」的 QP 求解器，適合對即時性與安全性要求極高的機器人控制場景。其主要貢獻是將 L1 松弛解析摺疊進求解器，使得系統規模不受約束數影響。限制方面，該方法僅處理線性不等式與二次目標；對非線性約束或更複雜的罰函數可能需要進一步延伸。未來工作可探索自適應懲罰權重、結合學習式約束預測，或推廣至非凸 QP 與整數變數的情境。
