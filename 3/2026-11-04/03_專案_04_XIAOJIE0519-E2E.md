## 在做什麼
E2E 是一個 R 語言套件，專為醫學診斷（分類）與預後（生存分析）應用提供易於構建的集成機器學習框架。它允許使用者快速訓練個別基礎模型，並透過 Bagging、Voting 與 Stacking 方法組合成強大的集成模型，同時內建視覺化與 SHAP 值解釋工具，以支援模型的評估與可解讀。

## 技術
E2E 完全以 R 語言實作，提供統一的介面來訓練常見的基礎學習者（如邏輯回歸、決策樹、隨機森林等），並內建 Bagging、Voting 與 Stacking 三種集成策略。此外，該套件整合 SHAP 套件以計算特徵貢獻值，並配備繪圖函式產生 ROC、校準曲線及特徵重要性圖，使模型開發與解釋流程可在同一環境中完成。

## 架構
E2E 的架構可視為四個主要模組：(1) 基礎模型訓練模組，負責呼叫使用者指定的演算法進行模型擬合；(2) 集成構建模組，實作 Bagging（自助抽樣平均）、Voting（多數決或平均機率）與 Stacking（次層模型）等方法；(3) 評估與視覺化模組，提供分類的 AUC、誤差率、生存分析的 C-index 等指標，並繪製 ROC、校準曲線；(4) 解釋模組，利用 SHAP 計算個體及全域特徵貢獻，並輸出摘要圖。使用者流程為：載入資料 → 指定基礎學習者 → 訓練個別模型 → 選擇集成策略 → 生成集成模型 → 評估效能 → 視覺化與解釋。若 README 未詳細說明內部依賴套件，則上述流程為基於文件所述功能的合理推斷。
