## 在做什麼
E2E 是一個 R 語言套件，專為醫學診斷（分類）與預後（生存分析）提供易於構建的集成機器學習框架。它允許使用者快速訓練單一模型並透過 Bagging、Voting、Stacking 等方法組合成強大的集成模型，同時內建視覺化與 SHAP 值解釋工具，以支援模型的評估與可解釋性。目標使用者為從事醫學研究、臨床預測或生物統計的研究者與資料科學家。

## 技術
E2E 以 R 為主要實作語言，提供統一的介面來訓練基礎學習器（如邏輯回歸、隨機森林、支持向量機等）並透過內建的 Bagging、Voting 與 Stacking 函數進行集成。為了模型解釋，套件整合了 SHAP 值計算與視覺化；為了結果呈現，提供了繪圖函數（依賴 R 基礎繪圖系統或 ggplot2）來顯示 ROC 曲線、生存曲線及特徵重要性。所有功能均以套件形式透過 CRAN 或 GitHub 安裝，並附有完整的文件與教學範例。

## 架構
E2E 的架構可概念化分為四個主要模組：(1) 資料預處理與特徵準備介面，接受使用者提供的資料框；(2) 基礎模型訓練模組，包含多種演算法的包裝函數，統一回傳模型物件；(3) 集成建構模組，實作 Bagging（bootstrap 抽樣）、Voting（多數決或平均機率）與 Stacking（次層模型）等策略，可依需求堆疊；(4) 評估與解釋模組，負責計算效能指標（AUC、C-index 等）、產生視覺化圖表以及利用 SHAP 計算特徵貢獻。資料流程為：原始資料 → 預處理 → 基礎模型訓練 → 集成組合 → 預測與效能評估 → 視覺化／SHAP 解釋。由於 README 未詳細說明內部依賴套件或具體類別結構，以上說明僅基於文件中描述的功能進行合理推斷。
