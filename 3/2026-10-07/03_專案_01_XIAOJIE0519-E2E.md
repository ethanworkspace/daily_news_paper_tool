## 在做什麼
E2E 是一個以 R 語言開發的套件，專門針對醫學領域的診斷（分類）與預後（生存分析）任務提供易於構建的集成機器學習框架。它允許使用者快速訓練單一基礎模型，並透過 Bagging、Voting、Stacking 等方法組合成強大的集成模型。套件內建模型評估、視覺化以及 SHAP 值解釋工具，幫助研究者與臨床工作者在不需深入程式細節的情況下，進行模型開發、性能比較與結果解釋。

## 技術
E2E 純以 R 語言實作，採用 S3/S4 物件系統封裝模型與集成流程，依賴常見的統計與機器學習套件（如 survival、randomForest、xgboost、gbm）進行基礎模型訓練；集成方式包括 Bagging（自助抽樣）、Voting（多數決或平均）與 Stacking（次層模型），並透過介面呼叫 shapr/fastshap 計算 SHAP 值，利用 ggplot2 生成特徵重要度、依賴圖與生存曲線等視覺化。套件提供統一的訓練、預測與解釋函式，降低使用者對底層程式碼的依賴。

## 架構
基於 README 的可見內容，E2E 的架構可大致分為四個主要模組：(1) 資料前處理與特徵準備函式，負責將原始臨床資料轉換為模型可接受的格式；(2) 模型訓練庫，提供單一演算法的包裝函式並支援超參數調整；(3) 集成建構層，實作 Bagging、Voting 與 Stacking 三種策略，並輸出統一的集成物件；(4) 評估與解釋模組，整合效能指標（AUC、C-index 等）、視覺化繪圖及 SHAP 值計算，供使用者進行模型比較與結果解釋。由於 README 未提供詳細的類別圖或函式呼叫圖，以上架構推斷僅基於所述功能描述。
