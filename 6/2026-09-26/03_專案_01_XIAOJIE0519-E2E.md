## 在做什麼
E2E 是一個以 R 語言實作的套件，專門為醫學領域的診斷（分類）與預後（生存分析）任務提供易於構建的集成機器學習框架。它允許使用者快速訓練單一基礎模型，並透過 Bagging、Voting、Stacking 等多種策略組合成強大的集成模型。除了模型訓練與預測外，E2E 還內建了模型評估、視覺化以及基於 SHAP 值的解釋工具，幫助研究者與臨床工作者在不撰寫複雜程式碼的情況下，完成從資料準備到模型解讀的全流程。該套件適合需要可重現、可擴展且具備解釋性的預測模型的醫學研究人員、生物統計師以及臨床決策支援系統的開發者。

## 技術
E2E 以 R 語言為開發基礎，利用 R 的套件管理系統（透過 remotes 從 GitHub 安裝）提供模型訓練、集成建構、評估與視覺化介面。套件內部呼叫現有 R 生態系統中的學習器（如隨機森林、廣義線性模型、生存分析套件等）作為基礎模型，並支援 Bagging、Voting 與 Stacking 三種主要的集成策略。為提升模型可解釋性，E2E 整合了 SHAP 套件來計算特徵貢獻度，並提供對應的視覺化函式。所有功能均透過 R 函式介面呈現，使用者可在 RStudio 或一般 R 環境中直接呼叫完成資料前處理、模型訓練、集成組合、效能評估與結果解釋等步驟。

## 架構
根據 README 的描述，E2E 的架構大致可分為以下幾個模組：(1) 資料輸入與前處理介面，使用者提供自行準備的特徵矩陣與生存或標籤資料；(2) 基礎模型訓練函式，負責呼叫底層學習器進行單一模型擬合；(3) 集成建構模組，實作 Bagging、Voting 與 Stacking 三種策略，將多個基礎模型的預測結果進行組合；(4) 模型評估與度量模組，提供分類與生存分析常見的效能指標（如 AUC、C-index 等）；(5) 視覺化與解釋模組，內建繪圖函式以及 SHAP 值計算與繪圖工具，用於特徵重要性與模型決策解釋。資料流程大致為：使用者輸入資料 → 前處理（視需求而定） → 基礎模型訓練 → 集成組合 → 預測與效能評估 → 視覺化／SHAP 解釋 → 結果輸出。由於 README 未提供詳細的類別圖或函式依賴清單，以上架構描述僅基於文件中提及的功能進行合理推斷。
