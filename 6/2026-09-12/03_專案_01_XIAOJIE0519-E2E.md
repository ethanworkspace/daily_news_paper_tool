## 在做什麼
E2E 是一個以 R 語言實作的套件，專門為醫學領域的診斷（分類）與預後（生存分析）任務提供易於構建的集成機器學習框架。它允許使用者快速訓練單一基礎模型，並透過 Bagging、Voting 與 Stacking 等方法組合成強大的集成模型。套件內建模型評估、視覺化以及 SHAP 值解釋工具，幫助研究者與臨床工作者在不撰寫複雜程式碼的情況下，完成模型開發、性能比較與結果解釋。目標使用者包括醫學研究員、生物統計師以及需要可解釋預測模型的臨床決策支援開發者。

## 技術
E2E 使用 R 語言開發，提供統一的函式介面來訓練任意符合預測器介面的基礎學習器（分類或生存分析模型）。內建三種集成策略：Bagging（自助抽樣重複訓練）、Voting（簡單平均或多數決）與 Stacking（次層模型）。模型解釋依賴 SHAP 套件計算特徵貢獻並產生摘要圖；視覺化功能繪製 ROC 曲線、校準圖、Kaplan-Meier 生存曲線等。資料流程為：輸入特徵矩陣與目標變數 → (選擇性) 前處理 → 基礎模型訓練 → 集成組合 → 預測與評估 → 解釋與視覺化。

## 架構
套件主要由四個模組組成：(1) 模型訓練模組，提供統一介面訓練分類或生存分析基礎學習器；(2) 集成建構模組，實作 Bagging（自助抽樣重複訓練）、Voting（簡單平均或多數決）與 Stacking（次層模型）三種策略；(3) 評估與視覺化模組，計算 AUC、C-index、Brier 分數等指標，並繪製 ROC、校準圖、生存曲線；(4) 解釋模組，整合 SHAP 計算特徵貢獻並產生摘要圖與依賴圖。典型執行流程為：使用者載入資料後，呼叫訓練函式產生基礎模型列表；再呼叫集成函式選擇策略產生最終模型；最後使用預測、評估、解釋與視覺化函式完成報告。由於 README 未提供詳細類圖或流程圖，上述架構推斷基於所說明的功能與典型 R 套件組織方式。

** E2E** is a comprehensive R package designed to streamline the development, evaluation, and interpretation of machine learning models for both **diagnostic (classification)** and **prognostic (survival analysis)** tasks. It provides a robust, extensible framework for training individual models and building powerful ensembles—including Bagging, Voting, and Stacking—with minimal code.
