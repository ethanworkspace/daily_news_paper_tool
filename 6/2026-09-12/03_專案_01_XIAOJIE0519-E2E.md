## 在做什麼
E2E 是一個 R 套件，旨在提供簡單且彈性的集成機器學習框架，特別針對醫學領域的診斷（分類）與預後（存活分析）任務。它允許使用者快速訓練個別基礎模型，並透過 Bagging、Voting、Stacking 等策略構建強大的集成模型。套件內建 SHAP 值計算與視覺化工具，可解釋模型預測，並透過 pkgdown 網站提供完整文件與教學。目標使用者為醫學研究者、生物統計師及資料科學家，他們需要在小樣本或高維度臨床資料上進行可重複的模型開發與風險評估。

## 技術
E2E 以 R 語言實作，可經由 remotes 從 GitHub 安裝。其核心包含分類與存活分析的基礎學習器介面、Bagging、Voting、Stacking 三種集成方法的包裝函式、SHAP 值計算與視覺化，以及模型效能評估圖表。儘管 README 未列明具體依賴，但可見其建構於現有 R 機器學習與存活分析套件之上，提供統一介面以進行模型訓練、集成與解釋。

## 架構
E2E 的架構可視為三層：資料輸入層、模型與集成層、結果輸出與解釋層。使用者首先提供特徵矩陣與目標變數（分類或存活時間），並選擇基礎學習器（如 logistic regression、random forest、Cox PH 等）。在模型與集成層，E2E 會依序訓練每個基礎模型，然後根據選擇的策略（Bagging 進行自助抽樣與平均、Voting 進行多數決或平均機率、Stacking 使用次層模型進行線性或非線性組合）產生最終預測。最後，結果輸出層提供預測結果、效能指標（AUC、C-index 等）、SHAP 值與變數重要性圖表，以及透過 pkgdown 網站的互動文件供進一步探索。若 README 未詳細說明次層模型或自助抽樣實作，則此敘述為基於文件所述功能的合理推斷。
