## 在做什麼
E2E 是一個以 R 語言開發的套件，專門為醫學診斷（分類）與預後（生存分析）提供易於構建的集成機器學習框架。它允許使用者快速訓練單一模型，並透過 Bagging、Voting、Stacking 等方法組合成強大的集成模型，同時內建 SHAP 值解釋與視覺化工具，幫助研究者評估模型效能與解讀預測結果，目標使用者為醫學研究者、生物統計師及資料科學家。

## 技術
E2E 以 R 語言實作，核心功能包括訓練常見的分類與生存模型（如邏輯回歸、隨機森林、XGBoost 等）並提供 Bagging、Voting 與 Stacking 三種集成策略。模型解釋方面整合 SHAP library 計算特徵貢獻值，並搭配套件內建的圖形化視覺化函式（如特徵重要性、依賴圖、SHAP summary plot）進行結果呈現。套件可經由 remotes 從 GitHub 安裝，文件透過 pkgdown 網站提供完整教程與函式參考。

## 架構
E2E 的架構可視為四個主要模組：(1) 資料前處理與特徵準備函式，負責將原始資料轉換為模型可接受的格式；(2) 模型訓練模組，提供統一介面來擬合單一分類或生存模型；(3) 集成建構模組，實作 Bagging、Voting 與 Stacking，可將多個基礎模組合併為集成預測器；(4) 評估與解釋模組，內建效能指標計算（AUC、C-index 等）、SHAP 值計算以及各種視覺化函式，使用者可依序呼叫這些模組完成從資料到模型解讀的完整流程。若 README 未詳細說明內部依賴，以上說明乃基於典型 R 套件結構的合理推斷。
