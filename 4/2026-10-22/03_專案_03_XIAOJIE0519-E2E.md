## 在做什麼
E2E 是一個 R 套件，旨在提供簡單且彈性的集成機器學習框架，特別針對醫學領域的診斷（分類）與預後（生存分析）任務。它允許使用者快速訓練個別模型並透過 Bagging、Voting、Stacking 等方法構建集成模型，並內建視覺化與 SHAP 解釋工具，以支援研究與臨床決策。

## 技術
E2E 以 R 語言開發，透過標準的 R 函式與 S3/S4 物件系統提供模型訓練、集成與評估功能。套件內建 Bagging、Voting 與 Stacking 三種集成策略，並整合視覺化繪圖與 SHAP 值計算以解釋模型。開發流程利用 GitHub Actions 進行 R-CMD-check 與 pkgdown 建置，確保跨平台相容與文件自動生成。

## 架構
根據 README 的描述，可推論 E2E 的主要模組包括：資料輸入、基礎模型訓練、集成構建、效能評估以及視覺化/解釋。典型的資料流程為：使用者提供資料集與模型公式 → train_model() 產生多個基礎學習者（如分類或生存模型） → build_ensemble() 依據 Bagging、Voting 或 Stacking 策略將基礎學習者組合成集成模型 → evaluate() 計算相關指標（如 AUC、C-index 等） → plot() 或 shap() 函式產生視覺化圖表與 SHAP 值以解釋模型。由於 README 未詳細說明內部類別結構或具體依賴的套件，此架構說明僅基於可見的功能描述與一般 R 套件設計經驗進行推斷。
