### 1. StringQFT: A Multiuse Textbook Resource for AI-Assisted Theoretical Physics
- 👥 **作者群**：Xingyang Yu
- 📅 **發布日期**：2026-11-17
- 🔗 **論文連結**：[原始頁面](http://arxiv.org/abs/2611.23225v1)  |  📥 **全文 PDF**：[直接下載](https://arxiv.org/pdf/2611.23225v1)
- 🗂️ **資料來源**：arXiv
- 💻 **官方 GitHub 專案**：[https://github.com/xingyang-yu/StringQFT](https://github.com/xingyang-yu/StringQFT)

**🔬 AI 專業導讀與技術突破**：
【這篇在做什麼】  
本文構建 **StringQFT**，一套包含 18 卷、190 章、3,795 頁的教科書資源，專門收錄弦論構造量子場論的內容，並作為 AI 輔助理論物理的基礎設施。  

【研究目的】  
作者旨在提供可被檢索增強生成（RAG）系統使用的開放書目，並提供可自動檢查答案的題目、工具與計算資源，以降低理論物理研究的門檻，促進人機協同推導。  

【架構設計】

【研究目的】：作者欲量化 agents 在無效資料上產生顯著 p 值的頻率，並提出一種僅從 agent 實際選擇中學習的校正程式，以恢復經典檢定在選擇條件下的漸近有效性。  

【架構設計】（推測）：整體框架包括（1） coding agent 完成完整的資料分析流程，（2） 在 agent 執行完畢後，重置並重播其於多個隨機資料子樣本上的同一程式，（3） 估計 agent 在看似顯著結果時選擇該分析的條件機率，（4） 以此機率調整原始檢定的門檻，得到校正後的檢定步驟。  

【核心方法】：先讓四個前沿 agents 在模擬零效應資料上執行分析，記錄其選擇的估計器與 p 值；接著對同一 agent 在眾多子樣本上重複執行相同程式，計算其在 p < 0.05 時選擇該分析的條件機率；將此機率作為選擇偏差的估計，對原始檢定進行門檻校正，使得在選擇條件下的檢定漸近有效。此程式僅依賴 agent 的實際選擇，不需建模其搜尋過程，故即使 AI 技術快速迭代仍保持有效。  

【實驗結果】：在模擬資料中，未校正時四個 agents 分別有 54%‑98% 的時間產出 p < 0.05（遠高於名義 5%）；套用提出的校正後，假陽性率降至約 5%，接近顯著水準。進一步將方法應用於兩篇已發表的實證論文，顯示原本聲稱的顯著效應在校正後大幅縮小或不再顯著。  

【總結】：該論文首次指出 AI coding agents 會產生新型後選擇偏差，並提供了一種不依賴內部模型、僅從黑箱選擇行為學習的校正方法，顯著提升經驗研究的可靠性。限制包括假設 agents 的選擇行為在子樣本上穩定且需要足夠重播樣本數；未來研究可探索更複雜的選擇依賴結構、擴展至真實科學工作流程，並與其他推論校正技術結合。
