## 在做什麼
E2E 是一個以 R 語言實作的套件，專門針對醫學領域的診斷（分類）與預後（生存分析）任務，提供一個統一且彈性的框架來建立、訓練與評估單一模型以及各種集成學習方法，包括 Bagging、Voting 與 Stacking。該套件內建 SHAP 值計算與視覺化工具，使用戶能夠解釋模型預測，並透過簡單的函式呼叫完成特徵重要性、模型比較與結果報告，目標使用者為從事醫學研究、臨床預測或生物統計的研究者與資料科學家，他們需要快速原型化且可重複的集成模型工作流程。

## 技術
E2E 以 R 語言開發，透過 remotes 從 GitHub 安裝，核心功能包含：利用 R 的模型訓練介面（如 glm、randomForest、xgboost 等）建立基礎學習器；實作 Bagging、Voting 與 Stacking 三種集成策略；整合 SHAP 套件計算特徵貢獻值並提供圖形化解釋；內建繪圖函式（可能基於 ggplot2）用於模型效能視覺化與比較。該套件強調最少程式碼即可完成模型訓練、集成與解釋的完整流程。

## 架構
根據 README 描述，E2E 的架構大致可分為四個主要模組：(1) 資料輸入與前處理介面，接受使用者提供的特徵矩陣與標籤或生存時間；(2) 基礎模型訓練函式，支援多種演算法並回傳模型物件；(3) 集成層，實作 Bagging（自助取樣）、Voting（多數決或平均）與 Stacking（次層模型）等方法，將基礎模型組合為最終預測器；(4) 評估與解釋模組，內建效能指標計算（如 AUC、C-index）、SHAP 值擷取與視覺化，以及模型比較圖表。資料流程為：使用者資料 → 前處理 → 基礎模型訓練 → 集成組合 → 效能評估與解釋 → 結果輸出。由於 README 未提供詳細類圖或函式依賴，以上架構推斷僅基於所述功能描述。
