## 在做什麼
E2E 是一個專為醫學診斷（分類）和預後（生存分析）應用設計的 R 套件，旨在降低構建與評估集成機器學習模型的門檻。它提供統一的介面來訓練單一模型，並透過 Bagging、Voting 與 Stacking 等方法快速組合成強大的集成模型。目標使用者包括醫學研究者、臨床資料科學家以及需要可解釋、可視化模型結果的跨領域團隊，核心問題是如何在不撰寫大量樣板程式的情況下，同時獲得高效能的預測與可靠的模型解釋。

## 技術
E2E 以 R 語言實作，利用 R 的套件生態系統進行模型訓練與評估。套件內建了 Bagging、Voting 與 Stacking 三種集成策略，並整合了 SHAP 值計算工具以提供特徵貢獻的局部與全域解釋。此外，E2E 提供了視覺化函式（例如 ROC 曲線、生存曲線、特徵重要性圖），讓使用者可以直接在 R 環境中完成模型的訓練、集成、效能評估與解釋流程。雖然 README 未列出具體依賴的底層模型套件，但可見其設計圍繞 R 的統一模型介面（如 formula、predict）進行擴展。

## 架構
E2E 的架構可概念化為四個主要模組：(1) 模型訓練介面，接受資料與模型規格，返回訓練好的基礎學習器；(2) 集成建構子，依據使用者選擇的 Bagging、Voting 或 Stacking 方法，將多個基礎學習器組合成集成模型；(3) 評估與視覺化模組，提供分類（AUC、準確率等）與生存分析（C-index、Brier score等）的效能指標，並繪製對應圖表；(4) 解釋模組，透過 SHAP 計算特徵貢獻，並支援全域與局部解釋視覺化。資料流程為：原始資料 → 前處理（使用者自行處理） → 基礎模型訓練 → 集成組合 → 效能評估 → 視覺化與 SHAP 解釋。由於 README 只說明了功能與使用範例，未提供原始碼或詳細函式結構，因此上述架構說明是基於文件中描述的模組功能所做的合理推斷。
