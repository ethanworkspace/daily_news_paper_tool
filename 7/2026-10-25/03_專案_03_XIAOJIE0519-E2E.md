## 在做什麼
E2E 是一個以 R 語言實作的套件，專門針對醫學領域的診斷（分類）與預後（生存分析）任務，提供一個統一且彈性的框架，使研究者能夠快速訓練單一模型並透過 Bagging、Voting、Stacking 等方式構建強大的集成模型，並內建視覺化與 SHAP 值解釋工具，以提升模型的可用性與可解釋性。

## 技術
E2E 以 R 語言開發，利用 R 的模型介面（如 formula、predict）進行基礎學習者的訓練，支援 Bagging、Voting 與 Stacking 三種集成策略，並整合 SHAP 套件進行模型解釋與特徵重要性視覺化。套件透過 pkgdown 建置線上文檔，並使用 GitHub Actions 執行 R CMD check 與套件建置，確保跨平台穩定性。

## 架構
E2E 的架構可視為四個主要模組：(1) 資料與模型介面模組，負責公式解析與資料準備；(2) 基礎學習者訓練模組，提供統一函數呼叫各種 R 演算法；(3) 集成建構模組，依使用者選擇實作 Bagging、Voting 或 Stacking，返回集成模型物件；(4) 評估與解釋模組，內建效能指標計算、繪圖函數以及 SHAP 值計算與視覺化。使用者流程為：載入資料 → 指定模型類型 → 訓練基礎學習者 → 選擇集成方法 → 取得集成模型 → 進行預測、效能評估與解釋。若 README 未詳細說明內部實作，以上架構為基於所述功能的合理推斷。

It provides a robust, extensible framework for training individual models and building powerful ensembles—including Bagging, Voting, and Stacking—with minimal code.
