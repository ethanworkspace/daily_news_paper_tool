## 在做什麼
E2E 是一個專為醫學診斷（分類）與預後（生存分析）設計的 R 套件，旨在提供簡單且彈性的集成機器學習框架。它支援使用者快速訓練單一模型並透過 Bagging、Voting、Stacking 等方法構建強大的集成模型，同時內建 SHAP 值解釋與視覺化工具，幫助醫學研究者、臨床數據科學家與生物統計師在不需深度程式設計的情況下，完成模型開發、效能評估與結果解讀。

## 技術
E2E 以 R 語言開發，利用標準的 S3/S4 物件系統封裝模型訓練與預測函式。核心功能包括：基礎學習器（如 logistic regression、random forest、Cox proportional hazards）的包裝、三種集成策略（Bagging、Voting、Stacking）的實作、透過 SHAP 套件計算特徵貢獻度並生成解釋圖，以及內建的 ROC、校準曲線與生存曲線繪圖工具。套件透過 GitHub Actions 進行 R-CMD-check 與 pkgdown 部署，確保跨平台穩定性與文件即時更新。

## 架構
E2E 的架構可分為四個主要模組：(1) 資料與前處理介面，接受使用者提供的特徵矩陣與標籤（分類或生存時間）；(2) 模型庫與訓練函式，負責呼叫基礎演算法並回傳統一的模型物件；(3) 集成引擎，依據使用者選擇的 Bagging、Voting 或 Stacking 方法，產生集成預測與不確定度估計；(4) 解釋與視覺化模組，計算 SHAP 值、繪製特徵重要性圖、ROC/PR 曲線及校準圖，並將結果輸出為 ggplot2 物件或 HTML 報告。資料流程為：原始資料 → 前處理 → 基礎模型訓練 → 集成組合 → 預測與效能評估 → 解釋與視覺化。由於 README 未詳細說明內部函式依賴，以上架構推斷基於所述功能與典型 R 套件設計。
