## 在做什麼
E2E 是一個 R 套件，旨在為醫學診斷（分類）和預後（生存分析）提供簡單易用的集成機器學習框架。目標使用者為醫學研究者、生物統計師與資料科學家，他們需要快速構建、比較與解釋個別模型及 Bagging、Voting、Stacking 等集成方法，以提升預測準確度與可解釋性。

## 技術
E2E 以 R 語言實作，核心功能依賴基礎統計與機器學習套件（如 glm、randomForest、survival、xgboost 等）進行個別模型訓練。集成層面提供 Bagging（自助抽樣）、Voting（多數決或平均）與 Stacking（次層模型）的通用介面。模型解釋利用 SHAP 值（透過 shapr/fastshap 等套件）產生特徵重要性，視覺化則基於 ggplot2 生成 ROC、校準曲線與生存曲線。套件亦內建交叉驗證與效能指標（AUC、C‑index、Brier 分數）計算函式。

## 架構
E2E 的架構可划分為四個主要模組：(1) 資料前處理與切分工具，負責載入資料集、處理缺失值、建立訓練/測試或交叉驗證折疊；(2) 模型訓練模組，提供統一介面來擬合分類（邏輯迴歸、隨機森林、SVM、XGBoost 等）與生存（Cox 比例風險、隨機森林生存模型）等基礎學習器；(3) 集成模組，依據使用者選擇的 Bagging、Voting 或 Stacking 策略，將基礎模型的預測進行自助抽樣、多數決/平均或次層模型堆疊，產生最終集成預測；(4) 評估與解釋模組，計算分類的 AUC、敏感度、特異度以及生存的 C‑index、Brier 分數，並透過 SHAP 值產生特徵貢獻圖，所有視覺化輸出均使用 ggplot2。資料流程為：原始資料 → 前處理 → 基礎模型訓練 → 集成預測 → 效能評估 → 解釋與視覺化。若 README 未詳細說明內部實作，以上描述以文件中提及的功能為推斷依據。

It provides a robust, extensible framework for training individual models and building powerful ensembles—including Bagging, Voting, and Stacking—with minimal code.
