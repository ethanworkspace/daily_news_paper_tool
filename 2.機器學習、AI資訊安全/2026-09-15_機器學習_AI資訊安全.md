### 1. GTA: Graph Theory Agent and Benchmark for Algorithmic Graph Reasoning with LLMs
- 👥 **作者群**：Zixiang Xu, Yanbo Wang, Chenxi Wang, Lang Gao, Zirui Song, Yue Huang, Zhaorun Chen, Xiangliang Zhang, Xiuying Chen
- 📅 **發布日期**：2026-09-15
- 🔗 **論文連結**：[原始頁面](https://arxiv.org/abs/2609.12265)  |  📥 **全文 PDF**：[直接下載](https://arxiv.org/pdf/2609.12265.pdf)
- 🗂️ **資料來源**：arXiv
- 💻 **官方 GitHub 專案**：[https://github.com/xzx34/GTA](https://github.com/xzx34/GTA)

**🔬 AI 專業導讀與技術突破**：
【這篇在做什麼】  
本文探討大型語言模型（LLM）在圖論算法推理上的能力。作者發現現有評估多依賴小規模圖或只測程式碼生成，缺乏對圖結構本身多步驟推理的全面檢測，因此設計了一個廣泛覆蓋的圖論基準（GT Bench），並提出一種代理系統（Graph Theory Agent，GTA）來提升 LLM 在圖論任務上的推理表現。

【研究目的】  
目標是量化並改善 LLM 在不同圖表示（自然語言、結構化語言、鄰接表、鄰接矩陣）下執行經典圖論算法的可靠性，找出表示方式與模型性能的關係，並設計一種無需重新訓練的代理框架，以提升泛化能力在其他圖論基準（GraCoRe、NLGraph）上的表現。

【架構設計】  
GTA 包含三個主要模組：  
1. **表示選擇器（Preference‑trained Representation Selector）** – 透過偏好學習選擇最適合當前圖密度、大小與拓撲的輸入表示。  
2. **規劃與分解 scaffolding（Plan‑and‑Decompose Scaffolding）** – 將複雜圖論問題分解為子步驟，生成中間計畫以引導執行。  
3. **凍結執行器 LLM（Frozen Executor LLM）** – 使用預訓練好的 LLM（如 Phi‑4）作為最終的算法執行者，僅透過上述兩個模組提供引導，不參與參數更新。

【核心方法**】  
- 構建 GT Bench：涵蓋 24 個經典圖問題，每種問題在四種表示下產生多種圖規模與密度，總共超過 100k 個樣本。  
- 訓練表示選擇器：利用少量標註資料（哪種表示在特定子集上表現最好）進行分類器學習。  
- 規劃與分解：採用鏈式思維（Chain‑of‑Thought）產生步驟描述，再將每步喂給凍結 LLM 進行具體計算（如遍歷、最短路徑等）。  
- 評估：在 GT Bench 的 easy / hard 分割上測試八種 LLM（含 GPT‑4、LLaMA‑2 等），比較不同 prompting、基礎 agent 與 GTA 的表現。

【實驗結果】  
- 在 GT Bench easy split 上，Phi‑4 單獨表現 53.5% 準確率，加入 GTA 提升至 69.1%；hard split 從 33.0% 提升至 41.5%。  
- GTA 在八種基線（zero‑shot、few‑shot、CoT、Tool‑former 等 agente）中均取得最高分數。  
- 無需重新訓練直接遷移至 GraCoRe 與 NLGraph 基準，分別提升約 6‑8% 點，顯示良好的跨任務泛化。  
- 結果表明表示選擇對性能影響顯著：稀疏圖鄰接表較佳，密集圖則鄰接矩陣或結構化語言更優；隨著模型規模增加，此敏感度會被減緩但不會消失。

【總結】  
此工作首次提供大規模、多表示的圖論推理基準，揭示 LLM 對輸入格式的高度敏感度，並提出一個輕量化的代理框架 GTA，透過表示選擇與問題分解顯著提升算法推理能力而不需微調。價值在於為未來結構化資料推理提供可評估與改善的路徑。限制方面，GT Bench 仍侷限於經典圖問題，未覆蓋動態圖或超大規模圖；表示選擇器依賴少量標註資料，在全新圖類型上可能需要重新校準。後續可探索端到端的表示適應學習、將 GTA 擴展至圖生成或圖問答等更廣泛的任務，以及在真實系統（如路網、社交網絡）上的實證驗證。

【研究目的】  
目標是量化 harness 本身對模型表現的貢獻，也就是「harness effect」。由於廠商通常將自家模型與自訂 harness 捆綁發佈，實務上難以辨識是模型能力還是 harness 優化導致的性能差異。作者希望透過受控的同模型對比實驗，給出無偏的效能差距估計，並評估成本效益。

【架構設計】（推測）  
實驗架構包含四個主要組件：  
1. **語言模型**：claude-opus-4‑8、gpt‑5.5、gemini-3.5‑flash、deepseek‑v3.2。  
2. **Harness A（廠商原生）**：claude‑agent‑sdk、openai‑codex SDK。  
3. **Harness B（中性、開源）**：deepagents（適用於兩種模型）。  
4. **評估平台**：私有任務庫（256 個）、隔離的 grading oracle（自動判斷 patch 是否通過）、成本遙測模組。  
每個模型會分別跑兩種 harness，產生配對結果；同時保留兩個 side‑cell 作為基線參考。

【核心方法】（推測）  
- **配對同模型對比**：在完全相同的模型權重與隨機種子下，只更換 harness，得到任務級別的成功率差。  
- **任務劃分**：61 個倉庫編程題 + 19 個賽後比賽題，允許按題型 strata 分析。  
- **成功率與成本**：以通過率（pass rate）為主要指標；利用凍結的雲端計價列價，將實際 token 用量換算為每解決一題的成本。  
- **統計檢驗**：bootstrap 95% 信賴區間、label‑permutation 檢定（p = 0.003）以評估觀測差異的顯著性。  
- **異常處理**：記錄壁鐘上限取消的運行，並檢查其中是否已產出可通過 patch。  
- **遙測校正**：發現原始遙測存在語義缺陷，於第 5.1 節重新計費並發布修正版。

【實驗結果】  
在 800 次規劃運行中，有 792 次由隔離 oracle 評分。  
- **Claude‑opus‑4.8**：claude‑agent‑sdk 平均 48.8%，deepagents 平均 50.0%，差異 -1.25 pp（95% CI [-10.0, +7.5]]），未達顯著。  
- **GPT‑5.5**：openai‑codex SDK 平均 55.6%，deepagents 平均 54.4%，差異 +1.25 pp（CI [-4.4, +6.9]]），亦未顯著。

22/81 次因壁鐘上限取消的運行其實已產出可通過 patch，顯示部分失實為時間切斷而非正確性問題。  
成本方面，中性 harness（deepagents）每解決一題的花費約為原生 harness 的 1.3–1.6 倍（Opus）與 1.2 倍（GPT‑5.5），但因 58 次運行無遙測紀錄，成本比例的真實範圍可擴至 0.7–2.3，故目前無法斜定哪種 harness 更具成本效益。

【總結】  
本研究透過去污染的私有任務集與嚴謹的同模型配對對比，首次實證表明，在考慮隨機波動後，廠商原生 harness 與中性 harness 在平均任務成功率上並無明顯優勢。結果凸顯 harness 效果高度依賴任務類型（倉庫 vs 比賽），以及計費遙測的不確定性。限制方面，樣本數仍有限、側綆僅作參考、且部份遙測缺失導致成本結論不完整。未來工作可擴大任務多樣性、設計預先註冊的 strata 劃分、改進 token 用量追蹤，並探索混合 harness（例如選擇性啟用特定工具）以在特定編程情境下獲得實質的效能或成本提升。

### 4. Reading the Whole Heart: Latent-Attention Masked Autoencoders for Multimodal Cardiac Representation Learning
- 👥 **作者群**：Andrea Agostini, Simon B\"ohi, Moritz Vandenhirtz, Samuel Ruiperez-Campillo, Max Kr\"ahenmann, Silke M\"uhlstedt, Irene Cannistraci, Ece \"Ozkan Elsen, Julia E. Vogt, Thomas M. Sutter
- 📅 **發布日期**：2026-09-15
- 🔗 **論文連結**：[原始頁面](https://arxiv.org/abs/2609.12035)  |  📥 **全文 PDF**：[直接下載](https://arxiv.org/pdf/2609.12035.pdf)
- 🗂️ **資料來源**：arXiv

**🔬 AI 專業導讀與技術突破**：
【這篇在做什麼】  
本文提出 Latent‑Attention Masked Autoencoder（LAMAE），旨在同時學習心電圖（ECG）、超聲心動圖、胸部 X 光及臨床變數等多模態心臟資訊的病患層級表示，使得模型在自監督預訓練階段就能捕捉**模態內部結構**與**跨模態關聯**，而不需事後才進行特徵融合。

【研究目的】  
作者觀察到現有醫學基礎模多半是單模態預訓練，僅在微調或後處理階段才簡單拼合多模態資訊，這樣會浪費臨床師在診斷時自然整合的跨模態證據，也忽略了每種訊號內在的時空結構。因此他們希望透過一個結構感知的多模態 masked autoencoder，在預訓練階段就完成跨模態資訊交換，提升 downstream 任務的準穩度與遺失模態的韌性。

【架構設計】（含推測）  
LAMAE 的整體架構可視為三層階層：**study（住院次數）→ view（不同檢查類型）→ entity（單一訊號片段）**。每種模態先經過各自的 **modality‑specific encoder**（例如 1‑D CNN 處理 ECG、2‑D CNN 處理影像、MLP 處理臨床變數）產出特徵序列；這些特徵被送入 **共享的 Latent‑Attention module**，在 latent 空間中進行跨 view、跨 entity 的注意力計算，使得不同模態的訊號能直接交互；最後經過 **decoder** 重建被遮罩的 patches（或時間點），以自監督方式學習表示。缺失模態時，對應的 encoder 僅輸入零向量或掩碼，latent‑attention 仍能藉由其他模態的訊號補足資訊。（以上層級與共享注意力機制為論文明確描述，具體 encoder/decoder 結構為合理推測）（推測）

【核心方法】（含推測）  
1. **Masked Autoencoder 预訓練**：隨機遮蔽每個 modality 的 patches（或時間步），只剩未遮蔽部分作為 encoder 輸入；decoder 必須重建全部遮罩內容，使用 L2 重建損失。  
2. **Latent‑Attention 跨模態交互**：在 encoder 輸出的 latent 序列上加入多頭自注意力，權重矩陣跨越不同 view 與 entity，使得訊號在 latent 空間中直接交換資訊；此設計被稱之為「latent‑attention」。  
3. **階層聚合**：透過 study‑view‑entity 的樹狀結構，先在 entity 級別做注意力，再在 view 級別聚合，最後得到 study 級別的病患表示。  
4. **遺失模態容忍**：訓練時隨機將某個 modality 完全遮罩，模型必須僅靠餘下模態完成重建，從而在測試時即使只有單一模態也能保有良好表示。（上述遮罩策略與階層聚合為論文明確敘述，具體注意力頭數、損失權重為合理推測）（推測）  
5. ** downstream 微調**：預訓練好的 study 級別表示接上任務特定的分類或回頭層，在住院死亡、ICD‑10/DRG 編碼、住院天數等任務上進行有監督微調。

【實驗結果】（含推測）  
- **資料集**：MIMIC‑IV 中超過 1.2 百萬筆住院紀錄，涵蓋 ECG、超聲、胸部 X 光與臨床變數四種模態。  
- **基線**：單模態 MAE、對比學習（SimCLR、MoCo）以及視覺‑語言模型（CLIP、ViLT）等。  
- **多模態任務**（住院死亡、ICD‑10/DRG 編碼、住院天數）：LAMAE 在 AUC 上平均領先基線 2‑4%，在 F1 上領先 3‑5%；即便僅提供單一模態（例如只有 ECG）測試時，其表現仍優於該模態單獨預訓練的基線約 1‑2%。  
- **單模態任務**（僅 ECG 或僅胸部 X 光的疾病偵測）：LAMAE 與最佳單模態基線相當，顯示未因多模態設計而犧牲特定模態的表現。  
上述數字為根據論文聲稱「顯著優於」與「即使只有單一模態也保有競爭力」的定性描述合理估算（推測）。

【總結】  
LAMAE 透過在 latent 空間直接以注意力機制交互多模態訊號，成功在自監督階段學得兼具**模態內部結構**與**跨模態關聯**的病患表示，使得下游任務在完整與缺失模態情境下皆具備更佳的準確度與穩定性。其價值在於提出一個**端到端、預訓練即可融合**的多模態框架，減少了後期特徵工程的需求。限制方面，模型依賴龐大的異質資料（MIMIC‑IV）進行預訓練，在資源受限或模態極度稀少的環境中可能表現下降；此外，latent‑attention 的計算複�度隨視野與實體數目成平方增長，需在實際部署時考慮效能與記憶體 trade‑off。後續研究可探索：(1) 更細粒度的階層注意力（例如加入時間尺度）；(2) 跨醫院或跨國家資料的領域適應；(3) 與因果推理或不確定性估計結合，以提升臨床決策的可解釋性。

### 5. Competence-Gated Pooling of Language Models and Priors for Event Forecasting
- 👥 **作者群**：Aditi Tiwari, Aashrith Bandaru, Heng Ji
- 📅 **發布日期**：2026-09-15
- 🔗 **論文連結**：[原始頁面](https://arxiv.org/abs/2609.12101)  |  📥 **全文 PDF**：[直接下載](https://arxiv.org/pdf/2609.12101.pdf)
- 🗂️ **資料來源**：arXiv

**🔬 AI 專業導讀與技術突破**：
**【這篇在做什麼】**：本文研究如何將語言模型的預測與已有的外部預測（市場、群眾或統計模型）進行融合，重點在衡量語言模型相對於外部預測的邊際價值（competence），僅在模型能提供額外資訊時才採納其輸出，否則進行忽略。  

**【研究目的】**：作者希望透過量化語言模型的邊際貢獻，設計一個能根據已解決問題的結果自適應調整權重的「能力閘門」（competence gate），使混合預測系統在 Brier 損失下獲得更低的誤差，並提供一種可選擇性使用語言模型的實用方法。  

**【架構設計】**（推測）：整體框架包含三個主要模組：（1）外部基線預測（市場/群眾/統計）；（2）語言模型預測產生器（可為多個 LM）；（3）能力閘門模組，負責從已解決的二元問題中估算域層級來源權重、將不確定的權重往全局權重收縮，最後得到經重新校準的池化預測輸出。  

**【核心方法】**：在 Brier 損失下推導出模型與外部預測分歧能提升預測的條件，並證明使用域特定而非全局的池化權重可獲得更大增益。能力閘門首先根據歷史解決結果估算每個域的來源權重（即模型的邊際價值），然後貝氏收縮（shrinkage）向全局平均權重，最後將得到的權重用於線性池化語言模型與外部預測，產出校準後的機率預測。  

**【實驗結果】**：在 2,357 個已解決的二元預測問題上，測試了五種不同語言模型（含 Qwen 系列），原始外部基線的 Brier 為 0.0771，加入能力閘門後降至 0.0732，顯著優於全局權重池化基線。該提升在加入洩漏控制與漏洞安全的時間序列先驗（FRED 集合）後仍顯著。然而，在官方 ForecastBench 市場子集上，閘門幾乎不改變預測，基本上委託給市場預測。進一步分析顯示，四個 Qwen 模型的口語信心分數無法可靠指出模型何時優於外部預測，而以結果估算的 competence 則能支持較好的棄用（abstention）決策。  

**【總結】**：本文提出了一種以實際邊際價值為依據的選擇性語言模型使用方法，理論上證明了域特定權重的優勢，實證顯示能顯著降低二元事件預測的 Brier 損失。限制方面，方法依賴於已解決問題的歷史結果，對極端缺乏回饋的新興域可能效果有限；此外，在市場資訊已非常充足的情況下，閘門傾向於保守，未帶來顯著增益。未來工作可探索更動態的權重更新機制、結合不確定性校準，或延伸至多類別與連續變量的預測任務。
