## 在做什麼
E2E 是一個以 R 語言實作的套件，專門為醫學領域的診斷（分類）與預後（生存分析）任務提供易於構建的集成機器學習框架。它讓使用者能以最少的程式碼訓練單一基礎模型，並透過 Bagging、Voting、Stacking 等方法組合成強大的集成模型，同時內建模型評估、視覺化與 SHAP 值解釋工具，幫助研究者快速開發、驗證與解釋預測模型。

## 技術
該套件完全使用 R 語言開發，依賴常見的機器學習與統計套件（如 caret、mlr3、survival、randomForest、xgboost 等）作為基礎學習器，並透過 S3/S4 類別系統封裝模型訓練、預測與集成功能。集成策略包括 Bagging（自助抽樣投票）、Voting（多數決或加權投票）與 Stacking（次層模型）。為了模型解釋，E2E 整合了 SHAP（shapley 值）計算與視覺化函式，並提供繪圖工具（ggplot2 基礎）來呈現 ROC 曲線、校準圖、生存曲線及特徵重要性。所有功能透過統一的 API 暴露，使用者只需載入套件即可呼叫對應函式進行資料準備、模型訓練、集成建構與結果解釋。

## 架構
E2E 的架構可視為三層結構：底層為基礎模型介面，負責呼叫各種 R 學習器進行訓練與預測；中間層為集成建構模組，提供 bagging、voting、stacking 函式，負責產生基礎模型的集合、進行次層模型訓練（僅適用於 stacking）並產生最終預測；上層為評估與解釋模組，包含效能指標計算（AUC、C-index 等）、視覺化繪圖以及 SHAP 值計算與繪圖。資料流程為：使用者提供處理好的特徵矩陣與目標變數 → 呼叫訓練函式產生基礎模型列表 → 透過選定的集成策略產生集成模型 → 使用集成模型對新資料進行預測 → 選擇性地呼叫解釋函式產生 SHAP 值與視覺化報告。由於 README 未詳細說明內部類別繼承或函式依賴圖，以上架構說明僅基於可見的功能描述與一般 R 套件設計慣例進行合理推斷。

It provides a robust, extensible framework for training individual models and building powerful ensembles—including Bagging, Voting, and Stacking—with minimal code.
