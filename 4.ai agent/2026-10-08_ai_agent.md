### 1. AdvSim2Real : Training Web Agents Against Adaptive Prompt Injection in a Web World Model
- 👥 **作者群**：Sarim Hashmi, Mukul Ranjan, Kshitij Mishra, Mikhail Kuznetsov, Praneeth Vepakomma et al.
- 📅 **發布日期**：2026-10-06
- 🔗 **論文連結**：[原始頁面](http://arxiv.org/abs/2610.08773v1)  |  📥 **全文 PDF**：[直接下載](https://arxiv.org/pdf/2610.08773v1)
- 🗂️ **資料來源**：arXiv
- 💻 **官方 GitHub 專案**：[https://github.com/Sarim-MBZUAI/advsim2real](https://github.com/Sarim-MBZUAI/advsim2real)

**🔬 AI 專業導讀與技術突破**：
【這篇在做什麼】：研究如何讓網頁代理（Web Agent）在面臨第三方頁面植入的 **prompt injection**（即惡意指令）時仍能完成使用者的真實任務。作者提出一個「AdvSim2Real」框架，在凍結的網頁世界模型中同步演進任務課程、對抗性注入與代理的訓練，使代理對適應性攻擊更具韌性。

【研究目的】：現有防禦多半只在靜態注入資料上微調代理，攻擊者可隨模型更新調整注入策略繞過防禦。作者希望透過 **對抗共進化**（co‑evolution）讓任務難度、攻擊策略與代理能力在同一訓練迴圈中相互提升，從而在未見過的攻擊下仍保持高任務完成率，並將模擬獲得的優勢遷移到真實瀏覽器環境。

【架構設計】：整體架構包含三個互耦合的模組：（1）**任務課程生成器**：根據代理當前成功率自動調整任務難度，目標是讓代理約 50% 的時間成功；（2）**注入對抗器**：產生能把先前判定為成功的任務翻轉為失敗的 prompt injection，僅在「成功翻轉」時給予獎勵；（3）**凍結網頁世界模型（Web World Model）**：預先訓練好的靜態網頁環境，提供可重複的頁面狀態與 DOM 結構，使代理、課程與對抗器在此模擬世界中進行互動。（推測）課程與對抗器各自採用強化學習策略，而代理則為大型語言模型（4B 參數）的策略網路。

【核心方法】：採用 **雙層對抗訓練**：內層是代理在當前課程與注入下最大化任務回報；外層分別更新課程（使成功率維持在 0.5 附近）與對抗器（最大化成功翻轉次數）。訓練全部在凍結的網頁世界模型中進行，避免真實網頁的額外開銷。訓練完成後，將得到的代理直接部署到真實瀏覽器進行實驗，以驗證遷移能力。（推測）使用 PPO 或類似的策略梯度算法，並以註入成功翻轉作為對抗器的獎訊號。

- 📅 **發布日期**：2026-10-06
- 🔗 **論文連結**：[原始頁面](http://arxiv.org/abs/2610.08430v1)  |  📥 **全文 PDF**：[直接下載](https://arxiv.org/pdf/2610.08430v1)

【這篇在做什麼】：針對大規模（至億萬億參數）的 agentic reinforcement learning（RL）提出一種「Delta‑Compressed Refit」機制，僅傳送參數的增量變化，以實現跨叢集的快速權重同步（refit），同時保證接收端得到與完整檢查點（dense refit）逐位相同的參數與緩衝區內容。

【研究目的】：現有跨區域傳輸完整 1T 參數檢查點耗時約 87.5 分鐘，嚴重限制了 agentic RL 的訓練迭代速度。作者觀察到每步只有約 1% 權重實際改變，嘗試利用這種稀疏性達到位置正確、逐位精確且高效的增量傳輸，同時避免現有方法在放置規則、完整張量重建或跨叢集集合通訊上的缺陷，並能從中途失敗中恢復。

【架構設計】：NeMo‑DCR 包含三個主要階段：（1）變化擷取與映射：訓練端依據固定的仿射映射將參數變化投射到檢查點的 canonical 座標；剩餘的無法投射變化則以剩餘轉換處理。（2）壓縮與傳送：使用可壓縮的 XOR mask 搬運可投射的仿射變化，另以直接覆寫（overwrite）處理其餘變化；payload 透過物件儲存或 relay tree 進行串流，無需跨叢集集體通訊。（3）接收端適用與提交：接收端就地適用 XOR mask 與 overwrite，失敗時重寫部分寫入，最後以 joint commit 將新策略與基準綁定，為下一輪 delta 做準備。

【核心方法】：關鍵在於位置不變的仿射投射與 XOR mask 的逐位不變性，使得壓縮後的資料在解壓縮與載入後正好恢復原始位元；剩餘變化以直接位元覆寫方式傳送，保證無誤差。採用物件儲存或 relay tree 進行增量資料流動，避免傳統 all‑reduce 或 broadcast 帶來的延遲與失敗點。實驗中設定 3% 與 5% 的權重變化率，測試 30B‑1T 模型的 refit 時間。

【實驗結果】：在 3% 變化率下，1T 模型的 relay‑tree refit 僅需 150 秒，相比傳輸完整檢查點的 87.5 分鐘（5250 秒）提升約 35×；即便在 5% 變化率下仍達 12‑40× 的加速。結果顯示 NeMo‑DCR 可將跨區域 agentic RL 的權重同步從不可行的分鐘級降至秒級，使得 trilion‑parameter 規模的訓練在實務上成為可能。

【總結】：該論文提出了一種既能達到逐位正確又極為節省帶寬的增量同步方案，解決了現有 sparse‑refit 方法在放置、精確度與失敗恢復上的缺失。其限制主要依賴於權重變化率的稀疏性假設（實際訓練中可能波動），以及對物件儲存或 relay tree 基礎設施的需求。後續研究可探索自適應變化率偵測、異質硬體上的載入器優化，以及將此技術擴展至其他大規模分散式學習任務（如大語言模型的參數同步）。
