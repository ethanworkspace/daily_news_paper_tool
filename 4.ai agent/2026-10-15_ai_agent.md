### 1. DoubtLess: Training-Free Contrastive Decoding for Efficient Reasoning
- 👥 **作者群**：Minghao Luo, Liang Chen
- 📅 **發布日期**：2026-10-13
- 🔗 **論文連結**：[原始頁面](http://arxiv.org/abs/2610.18862v1)  |  📥 **全文 PDF**：[直接下載](https://arxiv.org/pdf/2610.18862v1)
- 🗂️ **資料來源**：arXiv
- 💻 **官方 GitHub 專案**：[https://github.com/leoluolol/DoubtLess](https://github.com/leoluolol/DoubtLess)

**🔬 AI 專業導讀與技術突破**：
【這篇在做什麼】  
論文針對大型推理模型在產生長鏈思考（Chain‑of‑Thought, CoT）時常產生冗餘 token 的問題，提出一種無需額外訓練的對比解碼方法 DoubtLess，讓小型推理模型引導大型模型產出更簡潔的推理過程，同時保持答題正確率。

【研究目的】  
作者希望在不損失準確性的前提下，減少推理模型產生的思考 token 數，以降低計算成本與延遲；動機來自現有縮短 CoT 的做法往往需要額外訓練、固定調向或啟發式規則，易導致效能下降。

【架構設計】  
DoubtLess 的核心架構由兩個模型組成：  
1. 大型推理模型（例如 Qwen3‑32B）負責產生完整的 CoT；  
2. 更小的推理模型（同家族的輕量版）同時接受兩種提示：一次被引導簡潔（brief thinker）、一次被引導冗長（verbose thinker），產出兩組 logit 向量；  
3. 將兩組 logit 的差異乘以一個強度係數後，逐步加到大型模型的 logit 上，以影響後續 token 的選擇。整個過程在推理時完成，無需訓練或修改模型權重。

【核心方法】  
關鍵步驟包括：  
- 在每個解碼時間步，小型模型分別以「簡潔」和「冗長」提示前向傳播，得到兩組 logit；  
- 計算差異向量 Δ = logit_brief – logit_verbose；  
- 將 α·Δ（α 為超參數，控制影響強度）加到大型模型當前步的 logit 上；  
- 使用該修正後的 logit 進行下一個 token 的採樣。

- 📅 **發布日期**：2026-10-13

**🔬 AI 專業導讀與技術突破**：
**【這篇在做什麼】**（研究主題與解決的核心問題）  
本文提出 **Hybrid Reasoning Agents (HybridAgents)**，試圖讓代理人在內部進行高效的潛在（latent）推理，同時仍能透過自然語言與外部工具、環境互動。現有 LLM‑based agent 僅以文本進行推理與行動，雖然可直接調用工具但推理成本高；純潛在推理則缺乏工具接口與可檢視性。HybridAgents 想在同一生成流程中動態切換兩種模式，兼得工具整合與推理透明度。

**【研究目的】**（作者想達成什麼目標、動機為何）  
作者希望設計一種架構，使代理人能：  
1. 在需要深度抽象思考時，使用潛在空間進行高效推理；  
2. 在需要與工具或使用者交互時，切換回可解讀的文本模式；  
3. 保持跨輪對話的完整語境（lossless hybrid context），且不犧牲工具調用能力。  
最終目標是在保持或提升任務準確率的同時，大幅降低 token 消耗、提升推理速度並減少計算成本。

**【架構設計】**（提出的模型/系統/框架整體架構）  
- **HybridLink**：一個輕量級的轉接模組，負責在文本 token 序列與潛在向量之間進行無縫編碼/解碼，使模型能在同一次前向傳播中切換推理模式。  
- **連續工作記憶（Continuous Working Memory）**：在多輪對話中維護一個混合狀態緩衝區，既保存文本歷史又保存潛在思考軌跡，確保跨輪資訊不遺失。  
- **骨幹模型（Backbone LLM）**：採用現有預訓練大語言模型（如 LLaMA‑2、Mistral），僅透過 HybridLink 與工作記憶進行擴充，保持原有參數規模。  
- **後訓練階段**：分為 **HybridSFT**（監督微調）與 **HybridRL**（強化學習）兩個步驟，分別教模型如何協調 HybridLink 以及何時選擇潛在推理 vs. 文本行動。

**【核心方法】**（關鍵演算法、訓練方法、實驗設計或技術創新點）  
1. **HybridSFT**：在包含工具使用與潛在思考標註的混合資料上進行監督學習，使骨幹學會產生符合 HybridLink 接口的 token‑latent 混合序列。  
2. **HybridRL**：以任務回饋為獎勵，使用 PPO 或類似策略梯度算法，學習一個政策來決定在每個生成步驟中是否應該：  
   - 保持在潛在空間進行抽象推理（以減少 token），  
   - 或解碼為文本以調用工具或產生最終答案。  
3. **工具整合**：透過 HybridLink 的解碼端，潛在向量可直接映射為工具調用的參數，保證工具呼叫的即時性與可追溯性。  
4. **推理透明度**：因為所有潛在思考都會經過 HybridLink 編碼為可觀測的中間表示，研究者可在不影響效能的前提下檢視代理的內部推理軌跡。

**【實驗結果】**（在哪些資料集/場景驗證？量化成效如何？與基線比較？）  
- **模型規模**：分別在 7B、13B、33B 三種骨幹上進行實驗。  
- **基準測試**：涵蓋 11 個基準，包括 GSM‑8K、MATH、MedQA、ScienceQA、WebSearch、ToolFormer‑style 任務等，測試數學、科學、醫學、檢索與代理推理能力。  
- **主要指標**：相較於純文本 LLM Agent（如 ReAct、Toolformer）以及潛在推理基線（如 Latent Reasoning、思維鏈），HybridAgent 在所有基準上平均 **提升 10.4% 準確率**。  
- **效率 gains**：  
  - token 數減少 **35.5%–54.7%**（依模型大小而異），  
  - 推理速度提升 **1.8x–2.6x**，  
  - 計算成本下降 **2.7x–3.7x**（按 GPU‑hour 計）。  
- **消融實驗**：移除 HybridLink 或工作記憶皆導致顯著性能下降，證實兩者對混合推理的關鍵貢獻。

**【總結】**（這篇論文的價值、限制與後續研究啟發）  
HybridAgents 首次提出一個統一的生成框架，使代理人能在潛在與文本兩種模式之間自由切換，同時保持工具調用與推理可檢視性。實證顯示其在多領域任務上兼具準確率提升與顯著的資源節約，對於實務部署大規模 LLM Agent 具有重要意義。  
**限制**：  
- 依賴於額外的後訓練階段（SFT+RL），增加訓練複雜度。  
- 工具映射仍需手動設計 HybridLink 的解碼規則，泛化到完全未見工具時的表現有待驗證。  
- 工作記憶的固定長度可能在極長對話中導致資訊遺失。  
**後續方向**：探索自適應工作記憶容量、將 HybridLink 與外部檢索增強結合、以及在真實多工具環境中進行長 horizon 任務的評估。此外，減少後訓練對人類標註資料的依賴（例如使用自監督潛在思考產生）也是值得研究的課題。

【這篇在做什麼】本文針對大型語言模型（LLM）代理在多輪交互任務中的強化學習，提出解決無評論家（critic‑free）演算法（如 GRPO）在優勢分配上過於均勻的問題，使得結構不合理的動作也被同樣強化，導致樣本效率低與效能瓶頸。  

【研究目的】作者希望在不增加評論家額外開銷的情況下，實現細緻的責任歸屬，抑制無效動作的強化，同時利用早期關鍵偏離的 cascading 效應，提升代理在長 horizion 任務中的成功率與收斂速度。  

【架構設計】提出的 Progress‑Aware Advantage Shaping (ProAS) 框架由三個核心組件組成：（1）動態演進的 Agentic Reference Graph (ARG)，節點代表代理狀態，邊記錄狀態轉移的進度資訊；（2）Masking Unreasonable Incentives (MUI)，在 ARG 上檢測結構違規的動作並將其正向優勢設為零；（3）Asymmetric Penalty Redistribution (APR)，對負向優勢進行非對稱重新分配，使早期關鍵偏離獲得更大的懲罰，後續步驟則獲得較小的補償。ProAS 可直接插入現有的 group‑based 基線（如 GRPO）中，形成 plug‑and‑play 的訓練管線。  

【核心方法】關鍵步驟包括：(a) 在每個訓練批次中根據軌跡構建/更新 ARG，使用進度度量（如已完成子目標比例）作為邊權重；(b) 計算傳統群體優勢，然後透過 MUI 遮蔽不合理動作的正向優勢，並以 APR 將負優勢按進度非對稱分配；(c) 使用塑形後的優勢對策略網路進行梯度上升更新，無需評論家。實驗採用 Qwen2.5‑1.5B‑Instruct 與 Qwen2.5‑7B‑Instruct，在 ALFWorld 與 WebShop 基準上進行對比。  

【實驗結果】在 ALFWorld 上，ProAS 使 1.5B 模型成功率達 91.9%（基線 78.2%），7B 模型達 94.3%（基線 81.5%）；在 WebShop 上，成功率分別提升至 66.7%（基線 52.1%）與 70.8%（基線 55.3%）。訓練收斂速度提升最高達 2.44×，且對 ARG 的噪濫或蒸餾版本仍保持強健性。  

【總結】本文提出的無評論家細緻優勢塑造成為提升 LLM 代理多輪決策效能的有效途徑，證明在不增加模型參數的前提下可達到新狀態‑of‑the‑art。限制主要在於 ARG 的建構依賴領域知識或額外標註，可能難以直接泛化至完全未見的環境；未來可探索自動學習 ARG、跨任務遷移或與其他 critic‑free 演算法結合，以進一步提升普適用性。

### 5. Two Routes to Interoceptive Prioritisation: Dissociating Likelihood Precision and Preference Reweighting in Active Inference
- 👥 **作者群**：St John Grimbly, Nicolas Kuske, Evert A. Boonstra, Charel van Hoof, Rowan Hodson et al.
- 📅 **發布日期**：2026-10-13
- 🔗 **論文連結**：[原始頁面](http://arxiv.org/abs/2610.18617v1)  |  📥 **全文 PDF**：[直接下載](https://arxiv.org/pdf/2610.18617v1)
- 🗂️ **資料來源**：arXiv
- 💻 **官方 GitHub 專案**：[https://github.com/sgrimbly/interoceptive-prioritisation-iwai2026-snapshot](https://github.com/sgrimbly/interoceptive-prioritisation-iwai2026-snapshot)

**🔬 AI 專業導讀與技術突破**：
【這篇在做什麼】：研究主題是如何在主動推論（active inference）框架中，讓具備身體代理（embodied agent）在多種生理需求（如飢餓、口渴、體溫）之間進行優先排序。作者比較兩種干預方式：提升特定需求資訊的精度（likelihood precision）與重新權衡該需求的偏好（preference reweighting），觀察它們對生存率、感覺及身體模型學習的影響。（推測）  

【研究目的】：目的在於闡明「精度提升」與「偏好重權」兩種機制在代理的需求優先排序與身體感知學習中的差異與互動，以了解代理如何在緊急需求下調整其內部模型，並評估單一生存指標是否足以捕捉這些認知過程。（推測）  

【架構設計】：論文提出了一個基於格子世界（gridworld）的主動推論代理架構，包含：1）感知層（observation model）產生內感受訊號；2）精度調節模組（precision controller）可獨立提升特定需求的似然精度；3）偏好重權模組（preference weighter）調整效用函數中對應需求的權重；4）策略選擇層（policy selection）依據自由能最小化產生行動；5）身體模型更新層（body model learner）從經驗中更新內感受先驗。（推測）  

【核心方法】：關鍵方法是對同一個具有三種致命需求的 foraging gridworld 進行實驗，分別操作：❶ 增加目標需求的 likelihood precision（使後验分布更尖銳）；❷ 增加該需求的 preference weight（使代理更傾向於選擇緩解該需求的狀態）；❸ 兩者同時進行。訓練採用標準的積分近似（gradient‑free）主動推論演算法，並在 72 個不同布局的環境中測試泛化能力。（推測）  

【實驗結果】：在原始布局中，精度提升顯著銳利內感受後验並提升平均存活率；偏好重權則使代理的身體狀態遠離致命界限，導致學習到的身體模型涵蓋的需求水準較少、整體品質略降，但在實際訪問的水準上品質略高。在額外的 72 個布局中，單獨的偏好重益未達顯著預期提升，但兩種干預皆提升平均存活率，且它们的交互項為正，顯示有協同效應。僅看存活率無法完整反映模型如何優先需求與學習身體。（推測）  

【總結】：該研究提供了主動推論中兩種可拆解的需求優先機制的實證比較，凸顯了感覺精度與動機偏好在生存與模型學習中的不同貢獻，價值在於理清代理內部更新的多重途徑。限制主要在於實驗環境相對簡單（格子世界）及對偏好重益的預期未在難度更高的布局中得到證實，後續可嘗試更具連續性與噪聲的身體模擬平台，或引入神經科學實驗來驗證 precision vs. preference 的腦機制。
