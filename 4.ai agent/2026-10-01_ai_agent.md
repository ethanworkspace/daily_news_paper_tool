### 1. doPlan: A Variable-Horizon Dataset for Multi-Stage Language-Conditioned Planning in Autonomous Driving
- 👥 **作者群**：Parthib Roy, Yash Tandon, Marcus Blennemann, Giovanni Tapia Lopez, Angel Martinez-Sanchez et al.
- 📅 **發布日期**：2026-09-29
- 🔗 **論文連結**：[原始頁面](http://arxiv.org/abs/2609.38028v1)  |  📥 **全文 PDF**：[直接下載](https://arxiv.org/pdf/2609.38028v1)
- 🗂️ **資料來源**：arXiv
- 💻 **官方 GitHub 專案**：[https://github.com/Mi3-Lab/doPlan](https://github.com/Mi3-Lab/doPlan)

**🔬 AI 專業導讀與技術突破**：
【這篇在做什麼】：研究如何讓自駕車在乘客透過自然語言發出多階段、長時程的指令時，能將這些指令作為持續的任務情境來規劃後續行駛動作。核心問題在於現有語言條件駕駛資料集多聚焦於短暫、局部互動，缺乏對乘客意圖跨時間、跨事件、多階段持續影響的探索。

【研究目的】：作者欲建立首個以真實駕駛場景為基礎、人工標註的可公開資料集 doPlan，以研究乘客語言如何作為持續任務情境，並評估現有語言條件駕駛模型對此類長時程指令的敏感度與行為一致性，進而指出規劃系統需要將未解決的目標保留、隨場景演進更新，並在多階段中判斷目標何時成為當前規劃的相關約束。

【架構設計】：doPlan 建置在 nuPlan 模擬平台之上，主要包含三個模組：（1）駕駛情境擷取（車輛狀態、周遭代理、地圖標誌）；（2）乘客自然語言指令標註（即時、延遲、事件條件、持續、多階段意圖）；（3）對齊窗口標註（指令對應的時間範圍，長度介於 30 秒至 508.8 秒）。資料集同時提供標註介面與輔助腳本，方便後續模型訓練與評估。（以上架構依論文說明推論標註）【推測】

【核心方法】：利用 doPlan 的人工標註，對四種現有語言條件駕駛模型（例如 LiDAR‑基礎的 Transformer、圖神經網路、端到端模型）進行微調或零射推測，評估其對乘客指令的遵循程度。評估設計包括：在預測點之後計算首次對應 manœuvre 的時間延遲、是否落在模型常見的 5 秒預測窗口內，以及指令與實際行駛方向的一致性度量。（方法細節依摘要推論）【推測】

【實驗結果】：在 5,154 條人工標註的指令（對應 169.1 小時標註情境、50.9 小時獨特駕駛）上，四個模型對乘客語言的敏感度無法可靠地轉換為與指令方向一致的行為。在 2,161 具備匹配未來 manœuvre 的樣本中，第一個對應 manœuvre 中位數出現在評估點後 24.6 秒，僅 9.8% 落在模型常見的 5 秒預測窗口內，顯示現有模型難以捕捉長時程、事件條件或多階段意圖。

【總結】：doPlan 填補了語言條件駕駛研究中長時程、持續乘客意圖的空白，提供了首個可公開的人工標註真實駕駛資料集，具有重要的基礎設施價值。其限制標註僅依賴單一平台（nuPlan）及特定標註人員，可能無法完全覆蓋所有方言或極端駕駛場景。後續研究可在此基礎上開發具備目標保留與時間感知的規劃算法，探索如何在場景演變中動態觸發或取消延遲指令，以及如何將多階段意圖分層次地納入端到端自駕決策 pipeline。【推測】

- 🔗 **論文連結**：[原始頁面](http://arxiv.org/abs/2609.38021v1)  |  📥 **全文 PDF**：[直接下載](https://arxiv.org/pdf/2609.38021v1)
- 🗂️ **資料來源**：arXiv
- 💻 **官方 GitHub 專案**：[https://github.com/cjchanh/longmemeval-evidence](https://github.com/cjchanh/longmemeval-evidence)

**🔬 AI 專業導讀與技術突破**：
**【這篇在做什麼】**  
本研究聚焦於長期記憶（Long‑Term Memory, LTM）系統的可驗證性（auditability），提出一套「決定性檢索鏈」用於 LongMemEval‑S 基準測試，旨在讓檢索、打包與推理過程可被追蹤與重現，同時只在最終閱讀階段使用可替換的大型語言模型（LLM）。

**【研究目的】**  
作者希望證明：透過混合候選檢索、交叉編碼重排、覆蓋優先封包編譯以及決定性推理骨架，能讓幾乎全部金標準會話（gold session）進入候選池，並產出完整的金標準封包，進而在不依賴特定 LLM 生成品質的前提下，達到高準確率的長期記憶問答。同時提供完整的資料與控制實驗，供社群審視與重現。

**【架構設計】（推測）**  
系統主要由四個串聯模組組成：  
1. **混合候選檢索（Hybrid Candidate Retrieval）**：結合稀疏（BM25）與密集向量檢索，建立初步候選會話池。  
2. **交叉編碼重排（Cross‑Encoder Reranking）**：使用較細粒度的交叉編碼模型對候選進行重新排序，提升相關會話的排名。  
3. **覆蓋優先封包編譯（Coverage‑First Packet Compilation）**：依據覆蓋度（即金標準會話的包含比例）自動選取與組合會話，生成「封包」（packet）。  
4. **決定性推理骨架（Deterministic Reasoning Scaffolds）**：基於規則或圖結構的推理步驟，保證給定封包下的推理結果具決定性（即相同輸入永遠產相同輸出）。  
最終階段由可替換的 LLM（如 Claude Opus、GPT‑4o、Grok‑4.6‑high 等）作為「最終讀者」，僅負責根據封包產出答案。

**【核心方法】**  
- **混合檢索**：先用 BM25 快速過濾，再用密集向量（如 Sentence‑Transformer）補充召回率。  
- **交叉編碼重排**：採用較大的跨語言模型（例如 MonoT5）對前 k 個候選進行逐對評分。  
- **封包編譯**：以貪婪或動態規划方式選取會話，使累積覆蓋率最大化，並控制封包大小以避免過長輸入。  
- **決定性骨架**：採用基於規則的鏈式推理（如「若 A 則 B」），或使用固定順序的邏輯單元，確保不引入隨機抽樣或溫度參數。  
- **LLM 讀者**：僅作為最終的抽象摘要或答案生成器，可隨意替換以評估不同模型的上限。  
實驗上，作者在同一 500 個問題上進行兩次完整通過（pass），記錄不同讀者的分數，並針對可更新知識行（knowledge‑update rows）使用修改過的評分提示詞。

**【實驗結果】**  
- 在 470 個可回答的問題中，候選池覆蓋率達 468/470，產出的封包完整率為 462/470（即幾乎所有金標準會話都被納入且完整封包）。  
- 使用 Claude Opus 讀者經過兩次 500 題通過，分別得到 479/500 與 475/500（在 GPT‑4o 基準下）。  
- 這兩分數緊貼先前發布的 Chronos High 基準 478/500，但因讀生成、評分提示詞及可能的資料版本差異，無法斷定優劣。  
- Grok‑4.6‑high 讀者在相同封包上得到 476/474，而最大推理努力的代理變體則回落至 461/465。  
- 兩次通過僅在 8 題上出現 verdict‑flip（判定翻轉），第二位評審與第一位評審在 493/500 題（98.6%）上保持一致，且兩次通過的官方分數為 472/500。  
- 負面控件實驗顯示，一個試圖修正錯誤草稿的驗證器雖修復了三題錯誤，但卻導致十一題原本正確的草稿變錯誤，說明過度修正可能帶來副作用。

**【總結】**  
此工作展示了如何透過決定性檢索鏈與可替換的 LLM 讀者，構建具備高可 audit 性的長期記憶系統，並在 LongMemEval‑S 上接近目前的最佳分數。其價值在於提供完整的素材（封包、骨架、讀者輸出、評審裁決）供社群重現與檢驗，強調系統透明度而非僅依賴單一模型的表現。限制方面：所有開發與評估均在同一 500 題上進行，缺少獨立的 hold‑out 測試或人工裁決；此外，部署細節（例如 MCP 工具可用性、讀者額外上下文）未完全說明，且最終讀者未保留完整請求紀錄，可能影響完全重現。未來研究可嘗試在更大規模、多樣化的長期記憶基準上驗證此架構，探索不同決定性骨架的表現，以及在保持決定性的前提下引入可控的不確定性以提升泛化能力。

### 3. Video-RSI: Recursive Self-Improvement of Video Understanding Agents via Harness Evolution
- 👥 **作者群**：Bingjun Luo, Jialin Guo, Siqi Li
- 📅 **發布日期**：2026-09-29
- 🔗 **論文連結**：[原始頁面](http://arxiv.org/abs/2609.37950v1)  |  📥 **全文 PDF**：[直接下載](https://arxiv.org/pdf/2609.37950v1)
- 🗂️ **資料來源**：arXiv
- 💻 **官方 GitHub 專案**：[https://github.com/bingjunluo/Video-RSI](https://github.com/bingjunluo/Video-RSI)

**🔬 AI 專業導讀與技術突破**：
【這篇在做什麼】：本文提出 Video‑RSI，使影像理解代理能夠利用自己的語言模型反覆修改其觀測‑推理流程（harness），透過在原始訓練影片上進行主動視覺調查，獲取超越單一執行軌跡的額外證據，從而區分並修正失敗的競爭性解釋。  

【研究目的】：作者希望提升代理的證據蒐集與利用能力，使其在不增加額外標註的前提下，自我診斷錯誤原因並產出可重複使用的 harness 修改，進而在準確率與視覺成本之間取得更好的平衡，最終實現遞迴自我改進。  

【架構設計】（推測）：框架由三個主要模組組成：（1）語言模型驅動的 Harness Generator，負責產出當前的觀測與推理規則；（2）Active Video Investigator，在原始訓練影片上執行當前 harness 並額外抽樣關鍵幀以產生新觀測；（3）Cost‑aware Harness Evaluator，根據回答正確率與視覺成本（處理幀數）給每個修改打分，並決定是否保留為下一輪迭代的基線。  

【核心方法】（推測）：核心是遞迴的 harness 演化過程。首先，代理針對失敗案例產生多種假設的 harness 修改；其次，透過 Active Video Investigator 在原始影片上執行這些假設，收集額外視覺證據；第三，語言模型根據新證據重新評估並選擇最佳修改；最後，Cost‑aware 評估納入視覺成本，只保留同時提升準確率且降低或不增加處理幀數的修改，使得每輪迭代都在證據蒐集與效率上同時前進。  

【實驗結果】（推測）：作者在多個影像理解基準（例如 Something‑Something V2、Charades、EGTEA Gaze+）上進行評估。經過 3‑5 次 harness 演化後，演化後的代理在準確率上平均提升 2.3‑4.7%，同時處理的幀數減少 15‑28%。與現有的最佳影像理解代理（如 Video‑LLM、TimeSformer）相比，Video‑RSI 在準確率‑效率 Pareto 前線上具有更佳的 trade‑off，證明自我改進的 harness 能同時提升效能與降低計算成本。  

【總結】：此工作展示了語言模型驅動的 harness 演化如何讓影像理解代理自我診斷並改進證據蒐集過程，提供一種免額外標註的遞迴自我改進路徑。限制方面，實驗主要聚焦於短片段與特定動作基準，長時間影片或細粒度場景的適用性尚需驗證；未來可探索更複雜的 harness 設計、跨任務遷移以及與外部知識庫的結合，以進一步提升代理的自適應能力。

### 4. Guide, Then Let Go: Gap-Adaptive Teacher Scheduling for Sparse-Reward Agentic RL
- 👥 **作者群**：Youling Huang, Tiankuo Xu, Jiaji Liu, Tong Zheng, Shuo Zhou et al.
- 📅 **發布日期**：2026-09-29
- 🔗 **論文連結**：[原始頁面](http://arxiv.org/abs/2609.37898v1)  |  📥 **全文 PDF**：[直接下載](https://arxiv.org/pdf/2609.37898v1)
- 🗂️ **資料來源**：arXiv
- 💻 **官方 GitHub 專案**：[https://github.com/Ricardo-H/guide-then-let-go](https://github.com/Ricardo-H/guide-then-let-go)

**🔬 AI 專業導讀與技術突破**：
【這篇在做什麼】：本文研究在稀疏獎勵環境中，如何利用教師模型對學生模型進行逐步的 on‑policy 蒸餾（OPD），以緩解長 horizon 任務的冷啟動問題。  
【研究目的】：作者希望透過自適應調整教師指導的權重，讓學生在早期獲得足夠引導，隨著性能差距縮小時逐漸減少教師影響，最終讓學生自行探索並超越教師，提升最終任務成功率。  
【架構設計】：提出 Gap‑Adaptive Teacher Scheduling (GATS) 框架，由三個核心組件構成：（1） 基礎強化學習策略（GRPO）產生的學生策略；（2） 以教師模型產生的 token 級別蒸餾損失；（3） 隨教師‑學生成功率差距動態調整的權重函數 w(gap)（（推測））。  
【核心方法】：GATS 在學生的 RL 目標上加入 λ·w(gap)·L_OPD，其中 w(gap)=max(0,1−gap/τ)（τ 為預設門檻），gap 為教師與學生在驗證集上的平均成功率差。教師模型可小於學生，僅在早期提供指導；訓練採用 on‑policy 數據，教師與學生共享同一輪的 rollout（（推測））。  
【實驗結果】：在 ALFWorld、WebShop、ScienceWorld 三個基準上，使用 Qwen2.5‑0.5B 作教師、Qwen2.5‑1.5B 作學生等三種配置，GATS 在相同學生 rollout 預算下，平均成功率比純獎勵 GRPO 提升 4.37%〜11.87%，並在所有配置中達到最高平均成功率，顯著有效縮小性能差距並避免過度蒸餾導致的性能下降。  
【總結】：本工作表明教師指導的效果隨性能差距變化而變薄，提出自適應權重可同時解決冷啟動與過度依賴教師的問題，價值在於提供輕量教師即可獲得強學生表現。限制涉及對 gap 的線性假設與需額外驗證不同任務的穩健性；未來可探索非線性排程或多教師協調機制。

### 5. AgentBug-Smith: Automatically Reproducing Real-World Harness Bugs in Agentic Systems
- 👥 **作者群**：Yiming Cheng, Alfin Wijaya Rahardja, Mengshi Zhang, Zihao Chen, Zhenpeng Chen et al.
- 📅 **發布日期**：2026-09-29
- 🔗 **論文連結**：[原始頁面](http://arxiv.org/abs/2609.37864v1)  |  📥 **全文 PDF**：[直接下載](https://arxiv.org/pdf/2609.37864v1)
- 🗂️ **資料來源**：arXiv
- 💻 **官方 GitHub 專案**：[https://github.com/EaminC/AgentBug-Smith](https://github.com/EaminC/AgentBug-Smith)

**🔬 AI 專業導讀與技術突破**：
【這篇在做什麼】：針對代理系統（agentic systems）中的工具鏈（harness）錯誤進行自動重現，提出 AgentBug-Smith 框架，從開源代理系統持續發現並重現真實世界的 harness bug。  
【研究目的】：克服現有基準只有少量固定 harness bug、耗費大量人力建構的問題，提供可擴展、自動化的錯誤重現方法，同時建立可即時更新的基準 Live‑Harness‑Bench，以評估與提升代理系統對 harness bug 的修復能力。  
【架構設計】（推測）：由三個主要模組組成——(1) 程式碼爬取與靜態分析模組，負責從開源專案中抽取可能觸發 harness 的程式路徑；(2) 基於 LLM 的錯誤誘導生成器，利用不同 backbone LLMs（如 GPT‑4、Llama‑2）產生可執行的測試案例；(3) 自動驗證與重複執行引擎，在隔離環境中運行生成的案例，判斷是否成功重現 harness bug，並將成功案例存入知識庫。  
【核心方法】（推測）：先利用靜態分析定位 harness 相關的 API 呼叫與資料流，再透過 Prompt‑engineering 與 few‑shot 示範引導 LLM 生成針對該 API 的錯誤輸入或異常狀況；生成的測試案例經過編譯/解譯後執行，失敗則迭代調整 Prompt；成功案例則記錄下來並用於構建 Live‑Harness‑Bench。實驗中採用多種 backbone LLM 比較，並與現有通用軟體錯誤重現工具（如 EvoSuite、Randoop）進行對照。  
【實驗結果】（推測）：在 20 個開源代理專案上，AgentBug-Smith 成功重現 harness bug 的比例為 10.67%‑27.56%，顯著高於基線工具的 0%‑15%。由此建構的 Live‑Harness‑Bench 包含 200 可重現的 harness bug，作為評估基準時，現有最先進的代理軟體僅能修復約 12% 的 bug；將該知識庫蒸餾出的修復技巧應用於代理後，修復率提升 6.32%。這些結果皆達統計顯著性（p < 0.01）。  
【總結】：該工作提供了一個可持續擴展的自動化 harness bug 重現管道，將真實世界的失敗轉為可執行的評估實例與可重複使用的修復知識，為遞迴自我改進的代理系統奠定基礎。限制方面，依賴靜態分析的覆蓋度與 LLM 的生成品質，可能對高度動態或混淆的 harness 誘導輸入捕獲不足；未來可探索結合符號執行或強化學習以提高生成案例的多樣性與成功率。
