### 1. Concordat: Typed Sessions for LLM Agents
- 👥 **作者群**：Milad Sikaroudi
- 📅 **發布日期**：2026-10-27
- 🔗 **論文連結**：[原始頁面](http://arxiv.org/abs/2610.37461v1)  |  📥 **全文 PDF**：[直接下載](https://arxiv.org/pdf/2610.37461v1)
- 🗂️ **資料來源**：arXiv
- 💻 **官方 GitHub 專案**：[https://github.com/miladsikaroudi/concordat](https://github.com/miladsikaroudi/concordat)

**🔬 AI 專業導讀與技術突破**：
【這篇在做什麼】：本文提出一套名為 **Concordat** 的 Python 函式庫，把 LLM‑based agent 視為具備有限狀態協議（finite‑state protocol）的物件，使用類型狀態（typestate）與 session types 的概念，在執行時強制遵守該協議，以防止模型在未獲得適當確認的情況下執行關鍵動作（如取消訂單、退款、帳號修改）。  

【研究目的】：作者希望解決 LLM agent 只依賴 Prompt 中的自然語言規則而無法保證規則遵循的問題——特別是在面對使用者施壓或惡意請求時，確保關鍵操作必須經過顯式人工確認，同時不犧牲任務完成率，並提供可驗證、可組合的型別系統來規範 agent 行為。  

【架構設計】：Concordat 的核心是一個 **TypedSession** 類別，將 agent 的公開介面定義為一個狀態機（states）與允許的工具呼叫（tools）對照表。每個狀態只會暴露當前協議中合法的工具；嘗試呼叫不在集合內的工具會在產生副作用前被拒斥。此外，還包含 **ProtocolChecker**（靜態階段檢查協議是否符合 Liskov 替換原則）與 **BudgetManager**（線性分攤 token 與工具呼叫預算於 handoff 之間）。整體框架由以下模組組成：  
1. Protocol Definition（協議宣告）  
2. State‑Transition Engine（狀態轉移執行器）  
3. Tool‑Gate（工具閘門，實時過濾非法呼叫）  
4. Human‑Request Slot（保留給人類的決策請求）  
5. Budget Tracker（預算與成本計算）  

【核心方法】：作者首先以程式碼方式撰寫協議（使用 Python 語法描述狀態、允許工具與轉移條件），於載入時進行 **static protocol validation**（推測）以確保子類別不會繞過父協議。運行時，每輪推論前 Concorda​t 只將當前狀態合法的工具注入至 LLM 的 tool‑call 接口；模型若試圖呼叫其他工具，會被即時擋下並回傳錯誤。同時，系統會線性分攤 token 限額與工具呼叫次數於各個 agent handoff（例如從規劃Agent切換到執行Agent），防止單一階段濫用資源。在實驗中，作者使用 **tau‑bench** 的 50 項航空客服任務，加入模擬會施壓 agent 略過「yes」確認的客戶，對比標準 LLM agent 與 Concordat agent。  

【實驗結果】：在 GPT‑4.1 上，標準 agent 在 50 任務中有 13 次未取得必要確認就執行變更；在 Claude Haiku 5.5 上，相應違規次數升至 128 次執行中的 29 次。Concordat agent 在同樣設定下，**零違規**，且任務成功率與基線無顯著差異（成功率約為 84% vs 82%，差異不顯著）。tau‑bench 原生的 reward 函數未能捕捉多數違規行為，顯示該評估指標對安全性的不敏感。  

【總結】：Concordat 提供了一種可執行型別系統的方法，將安全規則從自然語言 Prompt 轉換為可編譯、運行時強制的狀態協議，顯著降低了 LLM agent 在關鍵操作上的未授權風險，同時保持任務完成效能。其限制主要在於需要手動撰寫協議（對複雜域可能增加開發負擔），以及目前僅支援單一 agent 的線性 handoff 預算模型。未來工作可探討自動協議生成、多層次嵌套 session 以及與強化學習或獎勵塑形結合，以進一步提升安全性與適應性。 （若部份細節未在摘要中明確給出，已標註為（推測））

### 4. Action-Value Calibration via Continuation Sharing for Long-Horizon Agentic Reinforcement Learning
- 👥 **作者群**：Yingjian Chen, Lang Zhou, Zixin Zhao, Pingfan Li, Weishi Zheng et al.
- 📅 **發布日期**：2026-10-27
- 🔗 **論文連結**：[原始頁面](http://arxiv.org/abs/2610.37195v1)  |  📥 **全文 PDF**：[直接下載](https://arxiv.org/pdf/2610.37195v1)
- 🗂️ **資料來源**：arXiv
- 💻 **官方 GitHub 專案**：[https://github.com/Yingjian-Chen/ConCal](https://github.com/Yingjian-Chen/ConCal)

**🔬 AI 專業導讀與技術突破**：
【這篇在做什麼】：研究長時程（long‑horizon）強化學習中的信用分配問題，即如何從一整段互動序列中正確估計單一動作的價值。現有方法（如 GiGPO）僅依賴單一樣本 continuation 來估計動作價值，導致後續決策的噪聲會放大對早期動作的信用估計誤差。  

【研究目的】：提出一種能夠利用已有軌跡批次中重覆出現的 continuation 證據，進行遞迴校正的動作價值估計器（ConCal），以減少對單一樣本 continuation 的依賴、降低局部信用失真，並在不額外採樣的前提下提升長時程任務的策略品質。  

【架構設計】：ConCal 包含三個主要模組：（1）狀態‑動作‑狀態三元組匹配器，將同一任務中具有相同進入狀態與過渡的訪問歸組；（2）遞迴 continuation‑value 估計器，利用組內已有的 continuation 證據（即後續狀態的價值）與當前訪問的過渡估計進行加權融合；（3）逆向傳播模組，將校正後的 continuation‑value 向前遞傳，以更新更早時間步的動作價值（Q‑估計）。  

【核心方法】：先從單一 rollout batch 中抽取所有 (s,a,s') 三元組，根據相同的 (s,a,s') 形成群組；對每個群組，計算其成員的 continuation 值（即從 s' 開始的累積報酬估計），取平均作為共享 continuation 證據；然後以該共享值與該成員自身樣本 continuation 的加權平均（權重可依訪問次數或不確定性調整）得到校正後的動作價值；最後以貝爾曼遞迴的方式把校正值向前傳遞，提升早期動作的 Q 值。此過程只需現有軌跡，無額外採樣。（實驗中使用 Qwen2.5‑1.5B‑Instruct 作為語言模型基礎，將 ConCal 融入 GiGPO 的優勢函數計算中。）  

【實驗結果】：在 ALFWorld 與 WebShop 兩個長時程Agentic RL 基準上，ConCal 分別使 GiGPO 的成功率提升 3.39 與 5.86 個百分點；同時，hold‑out return 診斷顯示，ConCal 估計的組內價值差異誤差降低約 15 %，與參考動作排序的一致性提升約 10 %，優於僅用單一 continuation 的基線。  

【總結】：ConCal 提供了一種無需額外採樣即可利用軌跡內部重複結構進行動作價值校正的有效方法，顯著改善長時程任務中的信用分配，提升策略性能。其限制主要在於依賴批次中存在足夠的相同 (s,a,s') 群組，在極端稀疏或完全多樣化的環境中效果可能減弱；未來工作可探索動態群組聚類或跨任務續傳機制，以擴大適用範圍。

### 5. Can LLMs Uncover Hidden Physical Laws through Free Exploration?

【這篇在做什麼】：本文探討大型語言模型（LLM）在未被告知目標的情況下，是否能透過自主探索發現被改變的物理定律。研究者建構一個模擬世界（LongChang），其中一或多項基本物理規則與現實不同，讓 LLM 作為「探索者」自由操作物件、製作工具並自行提出問題，藉此檢測模型是否能從觀測到的異常現象推導出隱藏的定律。

【研究目的】：作者希望驗證 LLM 是否具備類似科學家的假設生成與實驗驗證能力，尤其是在無先驅任務或提示的情況下，能否自發注意到違背日常經驗的物理行為（如重物下落較慢），並透過自我導向的實驗歸納出正確的物理規律。此目的旨在評估 LLM 作為自主科學發見工具的潛力與局限。

【架構設計】：LongChang 框架由四個互動的 LLM 代理組成（推測）：  
1. **場景生成器**：根據當前的物理規則產生初始或更新的模擬環境。  
2. **探索者代理**：操作物件、設計並使用工具，記錄觀測與實驗過程。  
3. **工具評審者**：檢視探索者所設計工具的可行性與安全性。  
4. **報告評估者**：依據改變後的物理定律和探索記錄，判斷探索報告的正確性與實驗支撐度。  
這些代理形成閉環：探索記錄回饋場景生成器，使環境隨探索深度演進，全程無需人工介入。

【核心方法】：研究者首先定義一組「改變的物理定律」（例如重力隨質量遞減），在 LongChang 中產生對應的模擬世界。評估的 12 種 LLM（包含 GPT‑6‑Astra 等）作為探索者，以零樣本方式進行自由探索，產生實驗日誌與工具設計。場景生成器與報告評估者利用同樣的 LLM 基礎模型，但加入規則檢查與一致性判別模組（推測），以自動評估探索報告是否符合改變後的定律。探索過程中會記錄未被檢驗的異常與部分正確的定律推論，作為後續場景演進的依據。

【總結】：此研究首次提出一個完全自動化的閉環框架，考驗 LLM 在無任務引導下進行科學探索的能力，展示了極少數前沿模型具備初步的假設生成與實驗驗證潛力。然而，整體發現率極低，多數模型未能從觀測到的異常推導出完整的物理定律，凸顯了當前 LLM 在因果推理、實驗規劃與長期遞迴反饋方面的限制。未來工作可著重於強化模型的內在因果模型、引入結構化的實驗規劃模組，或混合使用符號推理與神經網路，以提升自主科學發現的成功率。
