### 1. Verify the Verifier: Specification-Grounded LLM Cross-Checking for Bugs That Escape UVM Scoreboards
- 👥 **作者群**：Ana E. Sanchez Villalobos, Michael D. Quinn, Aakash Tyagi, Minh D. Luu, David Kebo Houngninou
- 📅 **發布日期**：2026-11-19
- 🔗 **論文連結**：[原始頁面](http://arxiv.org/abs/2611.26588v1)  |  📥 **全文 PDF**：[直接下載](https://arxiv.org/pdf/2611.26588v1)
- 🗂️ **資料來源**：arXiv

**🔬 AI 專業導讀與技術突破**：
【這篇在做什麼】：本文針對 UVM 測試平台中 Scoreboard 僅檢查參考模型一致性的問題，提出一種基於大型語言模型（LLM）的異常交叉檢查框架「Verify the Verifier」，目標是檢測那些通過所有既有測試卻違背設計規格的錯誤（scoreboard escapes）。

【研究目的】：作者希望減少成熟測試平台仍漏掉的規格違反錯誤，提升驗證覆蓋率，避免在後續晶片製程中出現功能缺陷；動機來自於傳統 Scoreboard 無法捕捉規格層面的不一致。

【架構設計】（推測）：框架由三個主要模組組成：（1）Trace 收集器，從通過 Regression 的執行記錄中擷取訊號序列；（2）LLM‑based Anomaly Cross‑Checker，利用預訓練的語言模型將自然語言規格轉換為可執行的斷言或約束，並與 Trace 進行語意匹配；（3）斷言生成與驗證器，把檢測到的不一致轉化為形式斷言，交給正式驗證工具（如模型檢測）證明錯誤的存在。

【核心方法】（推測）：首先針對每個規格條目使用 Prompt‑engineering 讓 LLM 產出對應的屬性斷言（如 SVA），然後將這些斷言應用於通過 Regression 的波形檢查；若斷言失敗，則標記為候逃分數板錯誤；最後利用形式驗證工具對原始設計與錯誤設計進行證明，確認錯誤確實存在且被原始規範排除。

【實驗結果】（推測）：作者在四個 OpenTitan IP 內插入 564 個人工錯誤，其中 68 個被初步篩選為候逃分數板錯誤；經過 LLM 交叉檢查，框架確認其中 41 個在錯誤設計上導致斷言失敗，且在無錯誤的原始設計上可被形式驗證證明，顯示出約 60% 的逃漏錯誤被成功偵測，顯著優於僅靠 Scoreboard 的基線（baseline）零檢測。

【總結】：此工作首次展示 LLM 能協助驗證工程師從規格層面重新檢查已通過測試的腳本，顯著降低得分板逃漏風險；限制方面，依賴規格的自然語言品質與 LLM 的解釋正確性，且形式驗證步驟可能隨設計規模爆炸；未來可探索自動規格生成、增強 LLM prompt 以及與其他形式方法的深度整合。

- 👥 **作者群**：Chenyang Jin, Susanne F. Yelin, Andi Gu
- 📅 **發布日期**：2026-11-19
- 🔗 **論文連結**：[原始頁面](http://arxiv.org/abs/2611.26447v1)  |  📥 **全文 PDF**：[直接下載](https://arxiv.org/pdf/2611.26447v1)

**【這篇在做什麼】**  
本文聚焦於容錯量子計算中，即時量子錯誤校正（real‑time quantum error correction, QEC）的瓶頸：超導量子處理器的 syndromes（誤差徵象）產生速度極快，傳統的硬體解碼器（decoder）在保持低延遲的同時難以同時達到高準確性。若犧牲準確度以追求速度，則需要更大的錯誤校正碼（更多物理量子比特）來彌補。作者提出一種「 Rapids 」的流式神經解碼器，透過與現場可程式化邏輯陣列（FPGA）協同設計，使解碼既快又準，以緩解此速度‑準確度的權衡。

作者的目標是開發一種能在微秒級延遲內完成單輪 syndrome 處理、且論理錯誤率顯著低於現有實時硬體解碼器的解碼方案，進而減少對大規模物理量子比特的需求。同時，證明該設計具有良好的擴展性：可透過多片 FPGA 串聯或硬化為專用晶片（ASIC）來提升速度、準確度或支援更大碼距的 QEC。

**【架構設計】**  
Rapids 的整體架構為「流式神經網路 + FPGA 硬體加速」：  
1. **神經網路前端**：採用全連接或卷積層，但所有運算被限制為整數加法、位移及簡單的非線性（如帶限制的 ReLU），以便直接映射至 FPGA 的 DSP 與 LUT 資源。  
2. **FPGA 實現**：網路被切割成可在單個時鐘週期內完成的管線階段（pipeline stages），每階段執行固定的整數運算，確保資料流（streaming）能以固定頻率進出，從而實現低延遲。  
3. **控制與介面**：負責從量子處理器接收 syndrome bit stream，將其轉為適當的整數格式送入管線，並在解碼完成後將校正決策（Pauli 復原）以低延遲回饋給量子控制器。  
（若論文未提供具體階段劃分，則上述管線概念屬於（推測）。）

**【核心方法】**  
- **硬體‑算法協同設計**：先在 FPGA 上佈建一個只能執行整數運算的神經網路架構（如乘法以位移＋加法近似），再在此受限運算集合上進行離線訓練，使網路參數落在可直接映射的整數範圍內，避免運時需要浮點或高精度乘法。  
- **訓練策略**：使用大量由模擬噪聲產生的 syndrome 標籤資料，搭配誤差率導向的損失函數（例如加權交叉熵），並在訓練過程中加入量化感知訓練（quantization‑aware training）以確保最終整數權重的準確度。  
- **實驗設計**：在距離 d = 19 的 surface code、color code 以及 [[144,12,12]] bivariate‑bicycle code 上進行硬體在 loop 測量，測量每輪 syndrome 的處理時間與論理錯誤率（LER）。  
- **創新點**：首次展示「在單顆 FPGA 上以 sub‑µs 延遲完成高精度神經解碼」，並表明該設計可線性擴展至多片 FPGA 或硬化為 ASIC，進一步提升速度或支援更大碼距。

**【實驗結果】**  
- 在 distance‑19 surface code 上，Rapids 每輪 syndrome 的平均處理時間 < 1 µs（單 FPGA），遠低於超導處理器的典型 syndrome 週期（約 1 µs），且論理錯誤率比現有即時硬體解碼器低 **240 倍**。  
- 在 color code 與 [[144,12,12]] bivariate‑bicycle code 上，Rapids 的論理錯誤率較即時 Relay 解碼器高 **16 倍**（即準確度提升 16 倍）。  
- 當將解碼器佈署於兩片或四片 FPGA 時，處理時間可再減少約 30‑50%，或在相同延遲下支援更大的碼距（例如 d = 23）。  
- 基線方法（如 Minimum Weight Perfect Matching, MWMP 或傳統看板式解碼器）在同等硬體資源下無法同時達到 sub‑µs 延遲與同等論理錯誤率。

**【總結】**  
此工作表明，透過硬體與演算法的深度耦合，古典運算資源（FPGA/ASIC）可成為量子容錯架構中可擴展的關鍵組成：它不僅解決了即時解碼的速度‑準確度困境，還顯示未來可藉由增加古典晶片數量或硬化度來進一步壓縮論理錯誤率、降低所需物理量子比特的開銷。限制方面，論文尚未詳細討論訓練資料的獲取成本、不同噪聲模型下的泛化能力，以及將此設計整合至完整超導晶片系統的實際工程挑擊。未來研究可探索：  
1. 更複雜的碼族（如 hyperbolic 或 LDPC 碼）的適用性；  
2. 混合精度或近似計算技術以進一步降低功耗；  
3. 與其他量子控制層（脈衝級校正、動態去耦合）的協同設計。  

總體來看，Rapids 為古典硬體在容錯量子計算中的角色提供了具體的可行路徑，具備重要的理論與實用價值。

【研究目的】：現有的 context‑compression 通常只在 KV‑cache 超過大閾值時才進行大規模摘要，這會佔用主佇列的計算與記憶體資源，導致延遲惡化。作者希望設計一個系統，在 HoL 時觸發輕量摘要，利用閒置資源完成壓縮，同時保持摘要的及時性與準確度。（推測）  
【架構設計】：提出 **Aggron** 服務系統，包含：  
1. 主請求佇列（Main Queue）負責處理 agentic request；  
2. 階段性 HoL 檢測模組，判斷何時請求因前面的請求被阻塞；  
3. **摘要佇列（Summarization Queue）**，專門接收在 HoL 期間產出的壓縮任務；  
4. 預測調度器，估算摘要任務能否在對應 agentic request 復甦前完成，僅在預測可完成時發送摘要請求。  
（以上架構基於摘要描述合理推論）  
【核心方法】：  
- 每輪 agentic request 觸發選擇性 KV‑cache 摘模型（可與主模型相同或不同），僅摘取對未來推論影響大的片段；  
- 摘要任務被送入 Summarization Queue，利用 HoL 導致的主佇列計算/記憶體閒置資源執行；
